# Coopanion v0.10.0

**英文界面、四位娘的冬装、更多模型服务、主动闲聊**

## 新功能

- **英文界面**：
  - 新装的 Coopanion 跟随系统语言：中文系统用中文，其他语言用英文。
  - 「习惯」页最上面可以切换中文 / English（设置 → 语言也行），切换后托盘菜单、设置窗口、启动引导、桌宠气泡、装扮窗口、电脑操作和模型服务的文字马上换成新语言，Coo 也用这种语言和你说话。
  - 英文新装默认称呼你「Pal」，语音输入听系统的语言。切换语言时，还是默认值的称呼和语音设置会跟着换，你自己改过的不动。
  - 选其他语言（日语、韩语等）时，Cortico 自带的页面用该语言，Coopanion 自己的文字显示英文，Coo 用你选的语言回话。
  - 已经装好的升级后仍是中文。以前只在设置 → 语言里把控制台切成英文的，升级后会回到中文，在「习惯」页选一次 English 即可，这次整个应用都会换成英文。
  - macOS 的麦克风和电脑操作权限说明、Windows 一键安装脚本也有了英文。
- **四位娘可以换冬装了**：装扮页给 Claude 娘、GPT 娘、Gemini 娘、Grok 娘多了一行「服装」，可以选「常服」或「冬装」。
  - 站着、坐着、跪坐、趴下、背过身、翻滚和各种手势都有冬装画面。
  - 换装是一帧切换，她正在坐着、跪着、趴着或做手势时换，姿势不会被打断。
  - Gemini 娘的「灵感」手势暂时没有冬装画面，冬装下用普通的冬装手臂做。
  - 导出的形象包（`pnpm run export:claude` 等）也带上冬装，原版 Coopanion（v0.1.17 起）装上就能选。
  - 冬装图是本项目照原画风格补画的，同样只限非商业使用，署名「ZipZipPipe（Bilibili）」。
- **更多模型服务**：新增 OpenAI、Anthropic、Gemini、xAI，默认模型都能看图。
  - 密钥填在应用里即可，不会被 shell 里设的 `OPENAI_API_KEY`、`ANTHROPIC_*` 等环境变量盖掉。
- **主动闲聊（默认关）**：在「习惯」页打开后，你在电脑前却有一阵没和 Coo 说话，或离开一会儿刚回来时，Coo 可能主动搭一两句；它也可以选择不出声。
  - 频率分少 / 中 / 多（至少隔 2 小时 / 1 小时 / 30 分钟），有免打扰时段（默认 23:00–08:00）。
  - Coo 被隐藏、暂停、睡着，或有全屏窗口（Windows）、你正在打字时都不会开口。
  - 每次尝试都是一次模型调用，Coo 没出声也算。
- **朝鼠标走**：Coo 可以走到你的鼠标旁边，或者躲开鼠标；鼠标在程序坞 / 任务栏上也认得。
- **启动引导可以选形象**：新装第一次启动时可以直接选 Coo、大肥鱼或四位娘，跳过就是 Coo。
- **装扮页导入形象包**：形象一行最后的「导入」可以装形象包（zip 或文件夹，也可以直接拖进来），先复制好再替换同名的旧版本，不动别的包。
- **大肥鱼的新表情和手臂**：
  - 新画了震惊、得意、偷笑、大哭、害怕、认真、慌张的嘴，以及认真、大哭的眼睛（8 套配色都有）；嫌弃改成皱眉的嘴。能合成一张脸的表情对从 106 个增加到 123 个。
  - 做表情时手臂也跟着摆：认真、生气时叉腰，期待时握拳，害羞、慌张时对手指，尴尬时挠头，嘟嘴、嫌弃时抱臂，拜托、唱歌时合十，听讲时拿出小本子。站着、坐着、跪坐，女仆装和冬装都有。
  - 跪坐时会凑近、后仰、轻轻摇晃。

## 改进

- **不再卡住不回话**：Cortico 升到 0.1.16，并带上之后的三处修复，解决了 Coo 偶尔卡住不再回话的问题。
- **时间跟随电脑的时区**：提醒和每日闹钟按电脑的时区走，跨夏令时仍在同一钟点。
- **数据目录被占用时说明原因**：另一个 Coopanion 还开着时，会提示是哪个进程，不再反复重启。
- **动作更顺**：
  - 换表情、入睡时抬头低头改成缓动。
  - 隐藏期间换了姿势，再显示时直接是新姿势，不再重播过渡。
  - GPT 娘、Gemini 娘坐着、跪坐时摇尾巴看得见了，GPT 娘趴着时也是。
- **新表情音效**：翻白眼、震惊、死鱼眼、流口水有了自己的声音。四位娘加回「担心 + 惊讶」这一对（135 → 136）。
- **表情决策**（默认关）：决策模型现在知道形象有尾巴、耳朵、翅膀，摆动这些部位不再占「一次最多动两处」的名额。
- **换装以最后一次点选为准**：快速连点两次服装时，不会再出现先点的那套后加载完、把后点的盖掉。
- **安装包**：打包时只带应用真正用到的文件，不再把测试和调试文件带进去；省下的空间被四位娘的冬装图片用掉了，Windows 版和 Apple 芯片版比 v0.9.1 大约 15 MB，Intel Mac 版差不多。

## 下载

- Windows x64：`Coopanion-Setup-0.10.0.exe`
- Apple 芯片 Mac：`Coopanion-0.10.0-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.10.0-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.10.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 及以后版本的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
