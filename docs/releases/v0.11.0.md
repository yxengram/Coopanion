# Coopanion v0.11.0

**表情决策恢复正常、ChatGPT 套餐登录（测试中）、Windows 便携版、Cortico 0.2.3**

## 重要修复

- **表情决策恢复正常**：原来的默认决策模型 `perplexity/pplx-decider-v1.1-27b` 已从 OpenRouter 下架，v0.10.0 里打开表情决策后，每句话都会退回本地挑选。
  - 默认决策模型换成 `typesafe/jev-1.14`。评测里它每次都成功，一次约 0.5 秒、约 0.0003 美元，挑出的表情和心情对得上的比例也最高。
  - 设置里还是旧默认值的会自动换成新的；自己填过别的模型的不动。
  - 以后选的模型被下架，这次运行会先改用默认模型，「习惯」页写明原因；默认模型也没了，就照旧在本地挑。
- **组合表情用得和以前一样多了**：升级 Cortico 后，给 Coo 的说明里各段的顺序变了，组合表情少用了约 4 个百分点。现在排回原来的顺序，每段文字一个字没改。

## 新功能

- **用 ChatGPT 套餐（测试中）**：有 ChatGPT 套餐的话，可以不填 API Key，在系统浏览器里登录 ChatGPT 账号，用量计入套餐。
  - 在「开始」页 OpenAI 旁边的 ChatGPT 卡片，或启动引导里选 OpenAI 后登录。
  - 登录凭据只存在这台电脑上，绑定数据所在的文件夹；复制或搬走的数据要重新登录。
  - 用到套餐上限时 Coo 不报错，每 5 分钟再试一次。
  - 这一项从上游移植，还没用真实账号完整测过，遇到问题欢迎反馈。
- **Windows 便携版**：`Coopanion-0.11.0-win-x64-portable.zip`，解压到任意有写入权限的文件夹就能用，数据放在旁边的 `data` 里。复制整个文件夹就是另一只。便携版不自动更新。
- **说的话留在桌宠旁边**：你打的字、说的话、在「对话」页发的消息，会以虚线气泡留在 Coo 旁边，最多 3 个，Coo 回复后淡出。
- **气泡和文字大小可调**：「习惯」页可以调气泡大小和文字大小。
- **按住说话键时才打开麦克风**（默认关）：在「语音输入」页打开后，麦克风只在按住说话键时打开。识别中的气泡里可以点「取消」丢掉这句。
- **气泡跟随形象的颜色**：气泡里选中的卡片、步骤圆点等跟着当前形象的主题色，不再总是 Coo 的绿色。
- **新版扩展市场**（随 Cortico 0.2.3）：扩展有标签、投票、评论和下载数，可以排序；用 GitHub 一次性验证码登录后就能投票和评论。

## 改进

- **Cortico 升到 0.2.3**，带来一批修复：
  - 卸载刚装不到 24 小时的扩展、卸载后重装，以及带原生模块的扩展，都能正常处理了。
  - 重启后不再重复投递已经处理过的消息，避免之后的请求全部被拒。
  - 对话交接时不再把最新的回答漏掉，Coo 不会把同一个问题回答两遍。
  - 内置的「终端」改名为「控制台」，旧数据启动时自动迁移。
- **设置页的桌宠预览不再是黑的**：「开始」和「装扮」页里能看到形象了。
- **电脑操作的风险说明**：电脑操作默认是开着的，第一次打开「电脑操作」页时会说明风险，可以选「保持打开」或「关掉」。高级模式 World 页的开关也会先问。
- **Windows**：
  - 自动更新装回原来的安装目录。
  - 托盘里「开机自动启动」的勾选显示正确。
  - 安装版换了目录时，启动会询问继承之前的数据还是新建一只。
- **启动问题说得更清楚**：设置窗口的端口全被占用时，提示会如实说明，不再误以为是刚更新过。
- **换语言时开着的引导气泡**就地换成新语言，已经输入的文字和选中的卡片保留；英文引导里说话键的提示不再夹中文。
- **形象**：
  - Gemini 娘冬装补上「有了」（拿灯泡），四位娘的冬装手势都齐了。
  - GPT 娘冬装 11 个手势的袖子切得更干净，没有残留的常服碎片。
  - GPT、Gemini、Grok 娘坐着做手势时，腰部不再发虚；Gemini 娘坐着做手势时不再多出两只手。
  - 大肥鱼走路时，手臂和同侧的腿反着摆。
- **更新提示**：正在后台下载新版本时，气泡里的第二个按钮改为「遇到问题？」，设置窗口的版本号下面显示下载进度。

## 下载

- Windows x64：`Coopanion-Setup-0.11.0.exe`（安装版）；`Coopanion-0.11.0-win-x64-portable.zip`（便携版）
- Apple 芯片 Mac：`Coopanion-0.11.0-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.11.0-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.11.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：八个下载文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 及以后版本的 Windows 安装版和 AppImage 会自动更新到这个版本；便携版要手动下载。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
