# Coopanion v0.2.0

**新形象 Claude 娘,35 个新表情和动作,默认不发使用统计**

这是 [yxengram/Coopanion](https://github.com/yxengram/Coopanion) 的第一个版本,在原版 Coopanion v0.1.17 的基础上加了下面这些。原版 v0.1.17 的全部功能和修复都在。

## 新功能

- **新形象 Claude 娘**:在装扮页的「形象」里选。一个正面站着的 Q 版少女,橙色波浪长发垂到膝盖,头上别着花饰,平时双手捧着一本书。她认得 71 个表情和动作(除了喷水,其他词都会):说话时每个字换一种口型;单手动作时另一只手还抱着书,双手动作时先把书放下;坐下时抱着书坐在铺开的裙摆上,趴下时趴在地上看书、脚丫翘起来晃,跪坐时把书放到一边;翻滚时团成一个球;转身、背过身时露出背影,长发跟着摆。她的图只限非商业使用,见 README 的许可一节。
- **35 个新表情和动作**,Coo 和 DeepSeek 大肥鱼都会,Claude 娘除了喷水也都会:
  - 表情:嫌弃、紧张、温柔、尴尬(苦笑)、偷笑、感动(笑着含泪)、石化(当场变成石像裂开,几秒后恢复)、撒娇、吐舌。
  - 动作:趴下、跪坐、比心、欢呼、后缩、探头、背过身、翻滚、喝茶、看书、喷水、叹气、拜托、挠头、有了(头顶亮起灯泡)、叉腰、抱抱、唱歌、奉茶、敬礼、比耶、指、捂嘴笑、抱臂、伸懒腰、屈膝礼。
  - 原有的词也更生动了:害羞时低头躲开,过一会儿偷看你一眼;难过时低头看地;跳舞时头发、裙摆和配件跟着甩;开心、得意时头旁闪一下小星星。
- **大肥鱼有了自己的画**:招手、欢呼、比心、托腮思考、喝茶、看书、拜托、叉腰、抱抱、奉茶、敬礼、比耶、伸懒腰、屈膝礼等用专门画的手臂;趴下、跪坐和团成球各有一整张画;转身、转圈转到一半露出背影;说话时换口型,趴着也会笑、会说话。
- **大肥鱼和 Claude 娘可以装进原版 Coopanion**:从源码运行 `pnpm run export:whale` 或 `pnpm run export:claude`,得到 `coopanion-whale`、`coopanion-claude-chan` 两个形象包,放进原版 v0.1.17 及以后的数据目录的 `home/companion/data/figures/` 就能用,上面这些表情和动作在原版里也都会做。

## 改进

- **翻滚靠着屏幕边也不打滑**:地方不够滚满一圈时,大肥鱼和 Claude 娘的球只转走过的那么多;Coo 还是转满一圈好站正,不够的那部分跳起来在半空里转。
- **Claude 娘细节打磨**:
  - 坐下、站起和跪坐时直接换成对应的画,不再有一瞬间两个身体叠在一起;跪坐直接从站着跪下,不再先坐一下。
  - 鞠躬时真的弯腰低头,屈膝礼也带一点;坐着也能鞠躬。
  - 背影长发大幅摆动时,披肩和领子不再错开,头发边缘不再露出硬边。
  - 大幅转头、摇头时,头顶轮廓不再有一道浅色细线,脸侧不再露出一条皮肤,花饰和刘海之间不再露出白色缺口。
  - 坐着招手时,裙摆旁不再出现奶白色的楔形色块。

## 其他

- **默认不发送使用统计**:只有用环境变量 `COOPANION_TELEMETRY_URL` 指定了统计服务器才会启用;平时不计数、不写文件、不联网,卸载时也不上报。设置窗口里去掉了这个开关。说明见 [docs/TELEMETRY.md](https://github.com/yxengram/Coopanion/blob/main/docs/TELEMETRY.md)。
- **自动更新和新版本提示改看这个仓库的发布页**。
- **从原版换过来,设置都还在**:程序标识和数据位置跟原版一样。Windows 版装到原来的安装位置就会沿用那里的 `data` 文件夹;macOS 和 Linux 的数据本来就在用户目录里。API Key、提示词、记忆和形象都不用重新设置。
- 提交贡献不再需要签贡献者协议,贡献按 AGPL-3.0-or-later 发布。

## 下载

- Windows x64:`Coopanion-Setup-0.2.0.exe`
- Apple 芯片 Mac:`Coopanion-0.2.0-mac-arm64.dmg` / `.zip`
- Intel Mac:`Coopanion-0.2.0-mac-x64.dmg` / `.zip`
- Linux x64:`Coopanion-0.2.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`:七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`:自动更新读的版本信息,不用下载。

装了这个版本的 Windows 版和 AppImage 以后会自动更新到这个仓库的新版本;原版装的 Coopanion 不会自动换过来,需要手动下载一次。macOS 版本仍是临时签名、未经 Apple 公证,第一次打开的方法见 README。
