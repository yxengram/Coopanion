# Coopanion v0.2.1

**新形象 GPT 娘**

## 新功能

- **新形象 GPT 娘**：在装扮页的「形象」里选。一个话少、清冷的 Q 版白色小龙娘，正面站着，白色波浪长发垂到膝盖，头顶一对龙角、尖耳朵，头侧别着绳结花饰，穿白色长裙和长长的荷叶袖，身后一对淡紫色龙翼和一条带鳞片的尾巴。
  - 龙翼和尾巴跟着心情动：开心时翅膀张开、尾巴摇起来；期待时翅膀一阵阵扑扇、尾巴尖翘起来；难过或睡着时翅膀收拢、尾巴耷拉下去；生气时翅膀会抖。
  - 她认得 71 个表情和动作，喷水以外的词都会做。说话时每个字换一种口型；看书捧着白色的书，写字拿笔记本和笔，找东西举起放大镜，喝茶端着白瓷茶杯。
  - 坐下时坐在铺开的裙摆上，尾巴盘在身前；趴下时趴着看书、脚丫翘起来；也会跪坐、团成一个球翻滚；转身和背过身时露出背影，长发跟着摆。
  - 角色设定来自 ZipZipPipe（Bilibili）画的 GPT 同人形象。她的图只限非商业使用，见 README 的许可一节。
- **GPT 娘也能装进原版 Coopanion**：从源码运行 `pnpm run export:gpt`，得到 `coopanion-gpt-chan` 形象包，放进原版 v0.1.17 及以后版本数据目录的 `home/companion/data/figures/` 就能用。

## 下载

- Windows x64：`Coopanion-Setup-0.2.1.exe`
- Apple 芯片 Mac：`Coopanion-0.2.1-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.2.1-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.2.1-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.0 的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
