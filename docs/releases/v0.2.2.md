# Coopanion v0.2.2

**新形象 Gemini 娘**

## 新功能

- **新形象 Gemini 娘**：在装扮页的「形象」里选。一个活泼的 Q 版猫耳少女，说话爱带「喵」，正面站着。她的长发是蓝紫到粉紫的渐变，垂到膝盖，扎着两个小发髻、翘着一根呆毛。头上一对猫耳，头侧别着彩虹色的星星发饰。她的眼睛一粉一金，穿深蓝短上衣和露肩白袖，身后有一条毛茸茸的猫尾巴。
  - **猫耳和尾巴跟着心情动**：开心、惊讶、认真听时耳朵竖起来，害怕、生气时贴平，困了耷拉下来，平时隔一会儿自己抖一下，被摸时一颤。尾巴平时慢慢甩成 S 形，开心时摇得飞快，吓一跳时炸毛，难过时垂下去，尾巴尖时不时弹一下。
  - **71 个表情和动作**：喷水以外的词都会。说话时每个字换一种口型。看书时捧着深蓝色的书，写字时拿羽毛笔，找东西时举放大镜，喝茶时端着茶杯。
  - **整身姿势**：坐下时尾巴盘在身前；趴下时趴着看书、脚丫翘起来；也会跪坐、团成一个球翻滚；转身和背过身时露出背影。
  - 角色设定来自 ZipZipPipe（Bilibili）画的 Gemini 同人形象。她的图只限非商业使用，见 README 的许可一节。
- **Gemini 娘也能装进原版 Coopanion**：从源码运行 `pnpm run export:gemini`，得到 `coopanion-gemini-chan` 形象包。放进原版 v0.1.17 及以后版本数据目录的 `home/companion/data/figures/` 就能用。

## 改进

- **Claude 娘的署名**改为 ZipZipPipe（Bilibili）。经查证，Claude 娘、GPT 娘和 Gemini 娘是同一位作者的同人形象。她的图同样只限非商业使用。
- **GPT 娘被拎起来时的嘴**：现在有她自己的波浪嘴。
- **GPT 娘跪坐起身不再闪一下**：从跪坐直接站起来，中间不再闪过一下坐姿的画。

## 下载

- Windows x64：`Coopanion-Setup-0.2.2.exe`
- Apple 芯片 Mac：`Coopanion-0.2.2-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.2.2-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.2.2-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.0 或 v0.2.1 的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版仍是临时签名、没有经过 Apple 公证，第一次打开的方法见 README。
