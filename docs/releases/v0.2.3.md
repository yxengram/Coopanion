# Coopanion v0.2.3

**形象切换更干净，几处画面瑕疵修好了**

## 改进

- **起身、趴下不再叠影**：Coo 以外的四个形象从趴着起身或趴下时，原来趴姿画和站姿会叠在一起几帧，现在一帧就切换过去。大肥鱼跪下、站起时也不再叠成两个头。
- **大肥鱼坐着起跳**：一离地就换成站姿，不再坐在半空。
- **Claude 娘跪坐起身**：直接站起来，中间不再闪一下抱书坐着的画。
- **三个娘从跪坐改坐下**：上身不再浮在半空。
- **GPT 娘坐下**：
  - 站姿的尾巴会淡出，不再和坐姿画里的尾巴叠成两条。
  - 下沉时鞋子不再半透明。
  - 后发里残留的尾巴和翅膀描边去掉了。
- **坐着做手势**：GPT 娘和 Gemini 娘膝上不再有一块糊掉的颜色。
- **晕眩**：三个娘晕的时候只有蚊香眼轻轻晃，睫毛不再跟着转圈。
- **Claude 娘背影**：长发甩到最大时，裙边不再露出一团模糊的橙色。

## 其他

- 三个娘的署名统一写作「ZipZipPipe（Bilibili）」，导出的形象包说明也一样。
- 只有设了 `COOPANION_TELEMETRY_URL` 才会发使用统计；开启时，装上的第三方形象包一律报告为 custom，不带它的名字。

## 下载

- Windows x64：`Coopanion-Setup-0.2.3.exe`
- Apple 芯片 Mac：`Coopanion-0.2.3-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.2.3-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.2.3-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
