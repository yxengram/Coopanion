# Coopanion v0.2.4

**两处小修复**

## 改进

- **GPT 娘背影**：头发边上的一圈碎点去掉了，转身和背过身时发边是一条完整的描边。
- **大肥鱼从跪坐站起**：保持跪姿直接站起来，中间不再先伸腿坐一下。跪坐后说「坐下」，还是会换成坐姿。

## 下载

- Windows x64：`Coopanion-Setup-0.2.4.exe`
- Apple 芯片 Mac：`Coopanion-0.2.4-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.2.4-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.2.4-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
