## 改进

## 下载

- Windows x64：`Coopanion-Setup-0.2.5.exe`
- Apple 芯片 Mac：`Coopanion-0.2.5-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.2.5-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.2.5-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
