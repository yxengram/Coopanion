# Coopanion v0.2.6

**表情动作的几处修复**

## 改进

- **说话里的动作不再丢**：写在一段没有文字的话里的 `<词>`（比如只写 `<眨眼>`，或 `【开心】<眨眼>`），现在会在这段话开始时照常做出来。
- **长距离走路不再被打断**：宽屏上走得久时，排在后面的动作会等她走完再开始。
- **走不了时立即说明**：被拎着、在空中、正在跳或翻滚时让她走路，会马上告诉 bot「身体正忙、还在哪里」，不再让 bot 等着。
- **坐、趴、睡、跪坐保持多久，告诉 bot 的说法更准确**：坐、趴、睡在做手势、换表情时会一直保持，换别的姿势或走、跑、跳才结束；跪坐遇到下一个动作（连点头也算）就变回普通坐着。
- **气泡对话里有当前形象不认得的词时，会写进日志**，不再悄悄略过。
- **大肥鱼紧张时也能招手**：「紧张」的时候，招手、欢呼、伸懒腰、挠头、指这几个动作的手臂画现在能正常显示。

## 其他

- 新增文档 `docs/notes/expressions-and-actions.md`：说明表情和动作是怎么被调用的，以及哪些可以同时出现、哪些会互相打断。
- 三位娘的代码里去掉了用不到的「喷水」部分（她们本来就不做喷水）。

## 下载

- Windows x64：`Coopanion-Setup-0.2.6.exe`
- Apple 芯片 Mac：`Coopanion-0.2.6-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.2.6-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.2.6-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
