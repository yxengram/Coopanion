# Coopanion v0.3.0

**表情和动作可以组合了，新增 23 个组合表情**

五个形象能同时出现的表情动作组合都多了好几倍（共 2278 对词里，Coo 从 231 对增加到 1104 对，Claude 娘从 154 对增加到 1079 对；一起下发时更多）。原来能同时出现的组合，一个都没少。

## 新功能

- **一次下发多个词**：`【开心+招手】` 这样用「+」（全角「＋」也行）连起来，就会同时做出来。说话、`pet_act` 和气泡对话里都能用。同一部位冲突的两个词（比如两个表情、两个姿势）会自动改成先后做，并告诉 bot。
- **23 个组合表情**：坏笑、俏皮、美滋滋、哈哈、笑哭、腼腆、心动、花痴、哇、馋、憧憬、跃跃欲试、无辜、气鼓鼓、抓狂、气哭、瘪嘴、哭唧唧、强颜欢笑、苦恼、狐疑、懵、呵呵。它们用现有表情的眼睛、嘴和身体动作拼成，五个形象都会。Coo 和大肥鱼现在认 95 个词，三位娘各认 94 个。

## 改进

- **指定的表情不会被动作清掉**：先说「得意」再「招手」，招手的整个过程都保持得意。唱歌、看书、喝茶时保留动作本身，只把眼睛换成指定的表情。
- **点头、摇头、叹气只动头**：能和招手、比心这些手臂动作同时做。
- **跪坐时可以换表情、点头、摇头、叹气**，不再先变成普通坐姿。做手臂动作时仍会先改成坐着。
- **被盖住的表情会接着显示**：倾听、晕、刚醒、睡觉时，指定的表情先暂停，结束后接着显示；被盖住超过 5 秒就不再显示。换表情也不再打断「张望」。

## 已知问题

- Coo 没有嘴，组合表情在她身上只有眼睛和整体姿态的变化，有几个和原表情差别不大。
- 大肥鱼没有得意、生气、难过、害羞的眼睛，「坏笑」「跃跃欲试」「气鼓鼓」「狐疑」在她身上不太明显。
- 和唱歌、看书、喝茶一起下发的表情只持续 3.2 秒，动作最后约 0.4 到 1.2 秒会变回动作自带的表情。

## 其他

- `docs/notes/expressions-and-actions.md` 更新了组合规则，附有改动前后的完整对比表。
- 四个形象包重新导出过，装进原版 Coopanion v0.1.17 后，所有词都能正常执行。

## 下载

- Windows x64：`Coopanion-Setup-0.3.0.exe`
- Apple 芯片 Mac：`Coopanion-0.3.0-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.3.0-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.3.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
