# Coopanion v0.4.0

**两个表情能拼成一张脸，跪坐时也能做手上的动作，跪坐、趴着时表情照常显示**

## 新功能

- **两个表情一起下，拼成一张脸**：同一组里写两个表情，比如 `【开心+惊讶】`，会显示成一张脸：一个表情的眼睛配另一个表情的嘴，先写哪个都行。能拼的组合是看过截图后挑出来的：三位娘 118 对、大肥鱼 81 对、Coo 24 对。原本就有的组合表情直接换成它，比如「得意+开心」就是坏笑。不在名单里的两个表情还是先后做，回执会告诉 bot 拼成了什么。
- **跪坐时也能做手上的动作**：大肥鱼和三位娘跪坐时可以招手、比心、敬礼、喝茶、看书、唱歌，做完仍然跪着。欢呼、鞠躬、转身这类要站着或坐着不动的动作，还是会让她变回普通坐姿。
- **跪坐、趴着时表情照常显示**：以前跪坐、趴着只能笑、闭眼、说话。现在所有表情、组合表情、拼成的脸、眨眼、眼神方向和说话口型都能看到，点头、摇头、叹气时脸也跟着头动。眉毛还是画上原有的。
- **大肥鱼补上四种眼睛**：得意、生气、难过、害羞现在有专门画的眼睛，8 套配色都有。坏笑、狐疑、腼腆、气鼓鼓、瘪嘴，以及用到这几种眼睛的表情对，都比以前明显。

## 改进

- **表情和动作一起下时，表情跟着动作**：和唱歌、看书、喝茶一起下的表情，会一直持续到动作做完，最后不再变回动作自带的脸。
- **bot 更会用表情**：给 bot 的说明里，表情按心情分组，组合表情放在对应心情里，规则旁边配了不同的例子，说明本身也更短了。实测 DeepSeek v4.1 flash 的 150 条回复，用 `+` 组合的从 70% 升到 89%，用组合表情的从 13% 升到 38%，写错被略过的词从 18 次降到 5 次。
- **Gemini 娘闭眼时不再有两层眉毛**。

## 其他

- 形象包的 `figure.json` 可以用 `pairs` 写出哪些表情能拼成一张脸，写法见桌宠包的 README。导出给原版 Coopanion（v0.1.17 起）的形象包照常能用。
- `docs/notes/expressions-and-actions.md` 补充了拼脸的规则、白名单是怎么挑的，以及 bot 实测的前后对比。

## 下载

- Windows x64：`Coopanion-Setup-0.4.0.exe`
- Apple 芯片 Mac：`Coopanion-0.4.0-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.4.0-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.4.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 或 v0.3.x 的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
