# Coopanion v0.4.1

**新动作「歪头」，bot 的表情动作更丰富**

## 新功能

- **歪头**：新的头部动作，也认「好奇」「歪脑袋」「偏头」。歪着头好奇地看一会儿再回正，可以和手上的动作一起做，站、坐、跪坐、趴着都会。

## 改进

- **bot 常写的说法也认得了**：挥手、摆手 → 招手；兴奋、眼睛亮 → 期待；打哈欠、揉眼、打盹 → 犯困；微笑 → 温柔；心疼 → 担心；站起来 → 站起；偷偷抬眼、移开视线 → 害羞；握拳 → 认真；轻轻点头 → 点头；抖抖 → 发抖。
- **bot 的表情动作更丰富**：给 bot 的说明改成先找对应心情的那组表情，再挑最贴切的一个，说话间配上点头、摇头、叹气、歪头。实测 DeepSeek v4.1 flash 的 150 条回复，用 `+` 组合的从 84% 升到 91%，点头、摇头、叹气、歪头从 47 次增加到 138 次，写错被略过的词从 10 次降到 5 次。
- **大肥鱼能拼的表情对从 81 对增加到 98 对**：她有了新的得意、生气、难过、害羞眼睛之后重新挑选，新增的有难过+开心、生气+得意、难过+惊讶等。
- 跪坐、趴着时连着做两个头部动作，头不会一下弹回原位。

## 其他

- CI 现在也会和原版 v0.1.17 逐帧比对、检查导出的形象包，三个系统都会跑。

## 下载

- Windows x64：`Coopanion-Setup-0.4.1.exe`
- Apple 芯片 Mac：`Coopanion-0.4.1-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.4.1-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.4.1-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 及以后版本的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
