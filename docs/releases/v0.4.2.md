# Coopanion v0.4.2

**几处画面瑕疵修好了**

## 改进

- **跪坐、趴着时脸上更干净**：大肥鱼和三位娘跪坐、趴着时，头发边上残留的旧睫毛尖、眼睛描边去掉了，睁眼闭眼都一样，大肥鱼的 8 套配色都改了。
- **大肥鱼眨眼**：得意、生气、难过、害羞这四种眼睛眨眼时，能看到闭着的眼皮和睫毛线，不再压成一条带颜色的细条。站、坐、转头、跪坐、趴着时都一样。
- **Gemini 娘的眼睛**：闭眼、半闭眼时两眼之间不再有几根杂发，眼皮上也不再有粉色、琥珀色的小色块。
- **Gemini 娘的下巴**：抬头、歪头时，下巴下面不再露出一条线。

## 下载

- Windows x64：`Coopanion-Setup-0.4.2.exe`
- Apple 芯片 Mac：`Coopanion-0.4.2-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.4.2-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.4.2-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 及以后版本的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
