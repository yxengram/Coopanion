# Coopanion v0.5.0

**新增 15–20 个表情和动作，全部用现有的图做成**

现在 Claude 娘认 111 个词，GPT 娘 113 个，Gemini 娘 115 个，大肥鱼 110 个，Coo 102 个（之前大肥鱼和 Coo 各 96 个，三位娘各 95 个）。

## 新功能

- **六个带特效的表情**：五个形象都有，和其他表情一样可以配任何动作。
  - 气炸：头两边冒气。
  - 心碎：头边一颗心裂开掉下。
  - 撒花：彩纸撒开。
  - 郁闷：头上一朵小乌云在下雨。
  - 无言以对：「……」一个点一个点冒出来。
  - 眼冒金星：> < 眼，头上转着星星。
- **以前只在某个表情里出现的手势，现在可以单独用**，能配任何表情，比如「生气+加油」「难过+对手指」。
  - 托腮：四个形象都有，三位娘是手指点着下巴，大肥鱼是手托着下巴。
  - 加油（握拳）、记笔记、对手指：只有三位娘有。
- **新的头部和身体动作**：大肥鱼和三位娘都有。
  - 低头、眨眨眼：头部动作，能和手上的动作一起做，跪坐时也不会起来。
  - 凑近、后仰、晃来晃去：上身的动作。
  - 跺脚：抬起前脚跺两下，带一点扬尘。
- **尾巴、耳朵、翅膀的动作**：能和表情、手上的动作一起做，做完尾巴、耳朵、翅膀再回到随心情的样子。
  - 摇尾巴：GPT 娘、Gemini 娘、大肥鱼。
  - 扇翅膀：GPT 娘。原地扇，不像「扑腾」那样跳起来。
  - 抖耳朵、竖耳朵、耳朵耷拉：Gemini 娘。

## 改进

- 新增别名：「连连点头」「猛点头」算点头，「使劲摇头」「拼命摇头」算摇头，「汗颜」算尴尬。

## 变化

- **三位娘的「握拳」改成新的「加油」**，以前算「认真」。大肥鱼和 Coo 的「握拳」仍是「认真」。

## 其他

- `docs/notes/expressions-and-actions.md` 补充了每个新词占身体哪个部位、跪坐和趴着时是什么样子。
- 导出给原版 Coopanion（v0.1.17 起）的形象包仍然可以用，新词在原版里也能执行。

## 下载

- Windows x64：`Coopanion-Setup-0.5.0.exe`
- Apple 芯片 Mac：`Coopanion-0.5.0-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.5.0-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.5.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 及以后版本的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
