# Coopanion v0.6.0

**七个新手势，新增「安慰」表情，以及几处脸部修正**

Claude 娘现在认 119 个词，GPT 娘 121 个，Gemini 娘 123 个，大肥鱼 118 个，Coo 103 个。

## 新功能

- **七个新手势**（大肥鱼和三位娘都有，大肥鱼 8 套配色都画了）：
  - 拍手（也认「鼓掌」）：两手一合一张，啪啪地拍。
  - 摊手（也认「耸肩」「没办法」）。
  - 抱头。
  - 举手（也认「我来」「我知道」）：手臂伸直举过头顶。
  - 点赞（也认「竖大拇指」「真棒」）。
  - 嘘（也认「小声点」「保密」）：竖起食指放在嘴前，眨一只眼，闭着嘴。
  - 擦汗（也认「好险」）。
  - 这些手势都能和任何表情、点头这类头部动作一起做，跪坐时也不会起来。
- **新表情「安慰」**（也认「没事的」「别难过」「宽心」）：五个形象都有。她看着你，眉头微微皱着，带着温柔的笑慢慢点头。「温柔」现在只表示微笑（也认「微笑」「欣慰」）。

## 改进

- **Gemini 娘的嘴放到了该在的位置**：以前所有的嘴都偏高，几乎贴着眼睛。现在站着、跪坐、趴着时，嘴都在两颊之间。
- **三位娘眨眼**：得意、生气、难过、害羞这些画好的眼睛眨眼时，能看到闭着的眼皮和睫毛线，不再压成一条深色细线。
- **bot 不再满口「温柔」**：实测 DeepSeek v4.1 flash 的 150 条回复，「温柔」从 110 次降到 84 次，陪人难过时改用「安慰」（28 次）。

## 其他

- `docs/notes/expressions-and-actions.md`：
  - 在 v0.5.0 上重新测了组合矩阵。
  - 补充了新词的实测：DeepSeek 用到了 16 种新词，Kimi 用到了 12 种。
- 导出给原版 Coopanion（v0.1.17 起）的形象包仍然可以用，新词在原版里也能执行。

## 下载

- Windows x64：`Coopanion-Setup-0.6.0.exe`
- Apple 芯片 Mac：`Coopanion-0.6.0-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.6.0-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.6.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 及以后版本的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
