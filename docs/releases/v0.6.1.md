# Coopanion v0.6.1

**眼泪变小，手势切换更干净**

## 改进

- **哭的时候不再有大泪滴盖住脸**：大肥鱼和三位娘的眼泪，现在是从眼睛下面冒出的小泪滴，顺着脸颊上的泪痕滑下，再从下巴滴落。大哭、笑哭、气哭、哭唧唧、难过、心碎、感动都一样，站、坐、跪坐、趴着时也一样，桌宠调大调小都合适。Coo 保持原样。
- **做手势时不再出现两只手**：以前手势开始和结束的那一下，新旧两只手臂会叠在一起半透明地显示一小会儿。现在在手臂交汇的那一帧直接换过去，站、坐、跪坐时都是这样。
- **大肥鱼的配色**：好几套配色的手臂和身体上原来有零星的黄色小点，现在基本去掉了。

## 下载

- Windows x64：`Coopanion-Setup-0.6.1.exe`
- Apple 芯片 Mac：`Coopanion-0.6.1-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.6.1-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.6.1-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 及以后版本的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
