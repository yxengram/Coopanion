# Coopanion v0.6.2

**新手势和新表情有了自己的音效，bot 少用「温柔」**

## 改进

- **新音效**：大肥鱼和三位娘的新手势、新表情有了合适的音效，一共 20 个。
  - 拍手是掌声，每次手掌合上的那一下响一声。
  - 嘘是「嘘」的气声，擦汗是「嗖」的一下。
  - 扇翅膀每往下扇一次响一声。
  - 摇尾巴、抖耳朵也有了声音。
  - 气炸时随着冒气发出嘶嘶声。
  - 心碎在心裂开的那一刻有一声轻轻的碎裂声。
  - 无言以对每冒出一个点就「哔」一声。
  - 撒花、郁闷、眼冒金星、安慰、加油、记笔记、对手指、点赞、举手、摊手、抱头也都换成了更贴切的声音。
  - 新音效的长短和音量都和原有的音效差不多。在声音设置里，它们分别归在「动作」和「表情」两个开关下。
- **音效开头不再「咔」一下**：以前每个合成音效开始的第一帧是满音量，偶尔会有一声细小的「咔」。现在第一帧是静音的。
- **bot 不再动不动就「温柔」**：「温柔」现在只用在对方好起来、跟她道谢时欣慰地笑。「奉茶」本来就带着温柔的笑，不用再另外加「温柔」。实测 DeepSeek v4.1 flash 的 150 条回复，屏幕上出现温柔脸的次数从 66 次降到 53 次，「安慰」从 22 次增加到 30 次。

## 其他

- 导出给原版 Coopanion（v0.1.17 起）的形象包会带上这些新音效，在原版里也能正常播放。

## 下载

- Windows x64：`Coopanion-Setup-0.6.2.exe`
- Apple 芯片 Mac：`Coopanion-0.6.2-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.6.2-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.6.2-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 及以后版本的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
