# Coopanion v0.7.0

**新形象：Grok 娘**

## 新功能

- **Grok 娘**（`grok-chan`）：金色双马尾的小吸血鬼。尖耳朵、小虎牙，头上戴一顶有齿轮的小王冠，两侧有蝙蝠翅膀发饰，穿红色衬里的黑色哥特裙。
  - 双马尾会随身体摆动、甩动；蝙蝠翅膀发饰会随心情张开或耷拉，「扇翅膀」时会扇动起来。
  - 其他三位娘有的她都有：所有表情、组合表情、118 对可以拼成一张脸的表情对，31 种手势，坐下、趴下、跪坐、翻滚、背过身；跪坐时也能做手上的动作，跪坐、趴着时表情照常显示；小泪滴，好好眨眼；手势切换时不重影，每个动作配有音效。
  - 一共认 120 个词。没有猫耳和尾巴的那四个词（摇尾巴、抖耳朵、竖耳朵、耳朵耷拉）。
  - 形象原作：ZipZipPipe（Bilibili），仅限非商业使用。
- 可以用 `pnpm run export:grok` 把她导出为原版 Coopanion（v0.1.17 起）能装的形象包 `coopanion-grok-chan`。

## 下载

- Windows x64：`Coopanion-Setup-0.7.0.exe`
- Apple 芯片 Mac：`Coopanion-0.7.0-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.7.0-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.7.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 及以后版本的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
