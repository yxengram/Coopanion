# Coopanion v0.8.0

**表情决策：bot 只写心情，表情动作交给决策模型挑（默认关）**

## 新功能

- **表情决策**（默认关，需要 OpenRouter 密钥）：打开后，bot 不再自己从一百多个词里挑表情动作，每说一句话只写一句此刻的心情或想法，你看不到这句话。然后由 OpenRouter 上的决策模型按这句话和当时的情形，给表情、头、手、身体和姿势各挑一个最贴切的，一起做出来。形象有尾巴、耳朵、翅膀的，这些也会挑。
  - **好处**：提示词里不再放整张词表，聊天模型每次调用的输入少了约四分之一。以后新加表情动作，或者装第三方形象包，都不用改提示词。
  - **实测**：DeepSeek v4.1 flash 配默认的决策模型 `perplexity/pplx-decider-v1.1-27b`，与 bot 自己写表情动作相比：
    - 聊天模型输入 token 总量少 27%，整轮用时相同；
    - 有表情的回复 96.6%（原来 95.8%），有动作的 97.5%（原来 99.2%），表情落在对应心情组的 91.3%（原来 95.7%）；
    - 决策模型每次约 0.9 秒、约 0.0001 美元。
  - **走动**：bot 自己决定往左还是往右走多少像素。它每次都知道自己在屏幕上的位置、面朝哪边、站着还是坐着；走到屏幕边会停下，并知道停在了哪。
  - **说话不用等**：气泡马上发出，表情动作挑好了就跟上。某次决策模型没回答或超时，那句话就只说话，下一句照常。
  - **在哪打开**：「习惯」页的「表情决策」卡片。卡片里可以从 OpenRouter 现有的决策模型里挑，会列出每百万输入 token 的价格和上下文长度。`typesafe/jev-1.14` 更快（约 0.5 秒），但贵一些。也可以在卡片里填一个 OpenRouter 密钥，这不会切换你正在用的聊天模型。
  - **隐私**：打开后，每句话都会把 bot 说的这句话、它写的心情、你最近说的一句话、它的姿势位置和时间，发给 OpenRouter 和它转给的决策模型服务商。默认关着，不打开就什么都不发；填了密钥也不会自动打开。
- **形象展示页**：在包目录运行 `node examples/whale/serve.mjs` 后打开页面。
  - 可以切换六个形象。
  - 表情按心情分组、动作按部位分组浏览，鼠标悬停能看到每个词的全部名字和样子说明。
  - 可以点播表情对，也可以在「组合」框里输入 `开心+招手+点头` 一起做。

## 下载

- Windows x64：`Coopanion-Setup-0.8.0.exe`
- Apple 芯片 Mac：`Coopanion-0.8.0-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.8.0-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.8.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 及以后版本的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
