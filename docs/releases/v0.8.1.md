# Coopanion v0.8.1

**四个新表情：翻白眼、震惊、死鱼眼、流口水**

## 新功能

- **四个新表情**，六个形象都有：
  - **翻白眼**：眼皮压平、眼珠翻上去，只看得见眼白。
  - **震惊**：眼睛发白、瞳孔缩成一点，头上一个「！」和三道黑线，整个人僵住发抖。比「惊讶」重。
  - **死鱼眼**：眼皮耷拉，无神地盯着你。
  - **流口水**：眯着眼出神，嘴角挂一滴口水。
  - 大肥鱼和四位娘的前三个是按原画风新画的眼睛，流口水有自己画的嘴，四位娘的震惊还有一张张大的嘴。Coo 用它的圆圈眼画。
  - 每个表情都有自己的音效。
  - 导出给原版 Coopanion（v0.1.17 起）的形象包里也有这四个表情，在原版里也能正常显示。
- **新的表情对**：同一组里写两个表情时，有 17 对新组合会合成一张脸（一个出眼睛、一个出嘴）。
  - 流口水的嘴配期待、喜欢、困、思考、尴尬、撒娇、认真的眼睛：馋了、打瞌睡流口水、盯上吃的。
  - 震惊的嘴配害怕、嫌弃、难过、喜欢、疑惑、害羞、担心的眼睛：吓到了、被恶心到、「啊？！」。
  - 还有翻白眼+吐舌、翻白眼+得意、死鱼眼+吐舌。
  - 四位娘一共认 135 对（原来 118 对），大肥鱼 106 对（原来 98 对，她的嘴小，只收了其中读得出来的 8 对），Coo 不变，24 对。
- 「眯眼笑」现在也能叫出「开心」。

## 其他

- 形象认的词数：Coo 107 个，大肥鱼 122 个，Claude 娘 123 个，GPT 娘 125 个，Gemini 娘 127 个，Grok 娘 124 个。
- **表情决策**（v0.8.0 的新功能，默认关）会自动用上这四个新表情，不用改设置。我们用新词表把之前的 193 个情形重新问了一遍默认的决策模型，结果和原来差不多：
  - 每句话平均 1.56 个表情（原来 1.57）；
  - 表情落在对应心情组的 91.3%（原来 93.5%），差别在正常波动之内。
  - 所以挑表情的门槛没有改。

## 下载

- Windows x64：`Coopanion-Setup-0.8.1.exe`
- Apple 芯片 Mac：`Coopanion-0.8.1-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.8.1-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.8.1-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 及以后版本的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
