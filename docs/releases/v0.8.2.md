# Coopanion v0.8.2

**动作不再抢在说话前面，启动更稳，Mac 上更省 GPU**

## 修复

- **动作按顺序来**：bot 说完几句话再做的动作，现在等最后一句的字打完才做，不会抢到前面去。之后要走路的话，先把这些动作做完再起步，最多等 6 秒，不会走到一半被「坐下」打断。说话中途你打开输入框时，还没做的动作也不会丢。
- **走远一点也不会误报没走到**：以前走路最多等 30 秒，宽屏上走得远就会提示「没走到」，其实她还在走。现在按路程算等多久。
- **表情决策模式下叫她睡觉，能睡成了**：要她睡下、趴下、坐下、跪坐时，姿势优先，不会再被同时挑中的表情或手势挤掉。
- **头发、尾巴、裙子偶尔永久消失**：遇到时间没有前进的一帧时会出现这个问题，现在修好了。大肥鱼和四位娘都加了防护，导出给原版 Coopanion 的形象包也一样。
- **换形象后新配色迟迟不出来**：修好了。
- **麦克风不再悄悄一直收音**：「按住说话」或「按一下开关」模式下，如果读不到说话键（比如 macOS 没给输入监控权限），以前会悄悄改成一直收音。现在不收音，并告诉你原因。
- **换装页更安全**：第三方形象包里的图片路径不会再被当成网页代码执行。

## 改进

- **启动更稳**：
  - 系统里装的证书（公司网络、杀毒软件的）也会被信任，不会再因为这个连不上模型。
  - 没有设代理环境变量时，会读系统的代理设置。
  - 刚更新完如果有文件还没放好，会先安静地重试几分钟。启动失败后再打开一次应用，会重新启动。
  - Windows 上数据目录写不进去时（比如装在了 Program Files），会弹窗说明后退出。安装器现在只为当前用户安装。
- **Mac 上更省 GPU**：光晕只画在身体周围，不再整个窗口一起模糊。特效（撒花、喷水、音符等）和刚走过的路径都算在光晕范围里，不会被裁掉。
- **表情决策**（默认关）：
  - 气泡等表情的时间从 0.9 秒放宽到 1.1 秒。实测默认决策模型一次中位数约 0.96 秒，现在约 85% 的表情能赶在打字前出来。
  - 翻白眼、震惊、死鱼眼、流口水的说明改成先写什么时候用。实测「中了大奖」这类场景会挑「震惊」了，其他场景的选择基本不变。
  - 备选决策模型里去掉了 `inception/mercury-decide:free`：开着零数据保留时它每次都会失败。
  - 更正 v0.8.1 的说法：默认决策模型对同样的问题每次给出完全相同的答案，所以 v0.8.1 里「落在对应心情组从 93.5% 到 91.3%」不是正常波动，是加了四个新表情带来的小变化。
- **反馈**：本仓库的 Issues 已经打开，有问题报告和功能建议两个模板。

## 下载

- Windows x64：`Coopanion-Setup-0.8.2.exe`
- Apple 芯片 Mac：`Coopanion-0.8.2-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.8.2-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.8.2-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 及以后版本的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
