# Coopanion v0.9.0

**大肥鱼的冬装**

## 新功能

- **大肥鱼可以换冬装了**：换装页给大肥鱼多了一行「服装」，可以选「女仆装」或「冬装」。
  - 冬装是一顶鲸鱼兜帽（头顶带鳍和喷水）、毛边斗篷、条纹围巾、毛绒袖口和毛口小鞋。
  - 冬装不随配色变，兜帽和斗篷始终是藏青色；头发、眼睛和尾巴照常跟着配色变。
  - 冬装下她能做的事和女仆装一样多：
    - 站着、坐着；
    - 37 种手势，袖口换成带小蓝蝴蝶结的毛绒袖口；
    - 跪坐，跪坐时也能做手势；
    - 趴下、睡觉、踢腿；
    - 背过身、转圈、翻滚。

    跪坐和趴着时表情照常显示。
  - 站着和坐着的冬装图来自上游 Coopanion（角色原设「溟月」（上善无形），二创 ZipZipPipe），其余姿势是本项目按同样的风格补画的。
  - 在上游 Coopanion 里选过冬装、再打开本项目时，也会正确显示成冬装。
- **导出的形象包也带上冬装**：`pnpm run export:whale` 导出的 `coopanion-whale` 包含全部冬装文件，原版 Coopanion（v0.1.17 起）装上就能选。

## 改进

- **大肥鱼跑起来更像样**：采用了上游改过的跑步动作，跑步时腰间不再露出腿。

## 下载

- Windows x64：`Coopanion-Setup-0.9.0.exe`
- Apple 芯片 Mac：`Coopanion-0.9.0-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.9.0-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.9.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 及以后版本的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
