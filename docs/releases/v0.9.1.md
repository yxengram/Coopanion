# Coopanion v0.9.1

**大肥鱼的三个新手势，安装包更小，桌宠窗口更稳**

## 新功能

- **大肥鱼新手势**：加油（举起小拳头给你打气）、记笔记（翻开小本子拿羽毛笔写）、对手指（两只手的指尖在胸前对着扭捏）。
  - 女仆装和冬装都有，8 套配色都能用。
  - 站着、坐着、跪坐都能做。
  - 大肥鱼现在认 125 个词。
  - 对大肥鱼说「握拳」，现在做的是「加油」（四位娘本来就是这样）。

## 改进

- **安装包小了约 25 MB**：打包时无损重新压缩形象图片，画面一个像素都不变；也不再带调试用的 sourcemap 文件。
- **翻滚更干净**：大肥鱼和四位娘翻滚时，站姿和团成球的样子一帧切换，不再叠在一起淡入淡出；球贴着地面滚，不再悬空或陷进地里。
- **桌宠窗口**（采用了上游的修复）：
  - 缩放固定为 1。
  - 窗口从最大化进入全屏时，桌宠也会让开。
  - Linux 上桌宠不会再挡住下面窗口的点击。
  - 页面卡住时会交还鼠标，不会一直占着。
  - 隐藏时静音，也不再绘制，省电；只有真的隐藏才会静音。
- **换形象时 bot 马上知道**：换了形象，bot 会被告知多了、少了哪些词，新形象做不了的词不会再提供给它。
- **表情决策**（默认关）：
  - 两个表情合成一张脸用得更多了：同样的 193 个情形里，表情落在对应心情组的从 76.6% 升到 78.2%，回复命中不变。
  - 决策模型没回答、超时或暂时用不了时，桌宠会按心情里点名的表情来做（最多一个表情加一个头部动作），不再干说话；回执里会注明。

## 下载

- Windows x64：`Coopanion-Setup-0.9.1.exe`
- Apple 芯片 Mac：`Coopanion-0.9.1-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.9.1-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.9.1-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

装了 v0.2.x 及以后版本的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。
