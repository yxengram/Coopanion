# 鲸鱼娘桌宠

B 站 DeepSeek 二创里的蓝发鲸鱼女仆，做成 Coo 的另一个身体。二头身（头顶到下巴 = 下巴到鞋底），和 Coo 一样侧身朝右站，转身时整组水平镜像。
她是一个形象包（`web/whale/figure.json`），身体用 kit（`web/kit/body.js`）：走、跑、跳、坐、睡、被拎起、甩出去、全部表情、倾听、思考、说话口型都由 kit 触发，她只负责画。

在本包目录运行 `node examples/whale/serve.mjs`，打开终端输出的地址（默认端口 4318），就是全部形象的展示页（见下面「展示页」）；
在 Claude Code 里也可以用仓库 `.claude/launch.json` 的 `figure-browser` 启动（端口 4318）。
真实桌宠里在装扮页（`/dress`）最上面一行「形象」选「DeepSeek 大肥鱼」，配色和服装在下面两行；选择存在配置的 `skin.figure` 和 `skin.scheme`（`<配色>-<服装>`，见「服装」）。

## 配色

| id | 名字 | 配色 |
|---|---|---|
| `deepseek` | DeepSeek | 原版蓝 |
| `harness` | DeepSeek Harness | 纯黑，只有胸针宝石是一点 DeepSeek 蓝 |
| `chatgpt` | ChatGPT | 银白头发、黑色衣服 |
| `claude` | Claude | 赤陶橙、暖米白、深陶棕 |
| `gemini` | Gemini | 蓝发、后发尾和鲸尾转绿、红呆毛和领结、黄蝴蝶结 |
| `qwen` | 千问 | 冷紫到薰衣草紫 |
| `kimi` | Kimi | 黑色，蓝色只在眼睛、蝴蝶结、宝石、鞋上的小结 |
| `minimax` | MiniMax | 头发从玫红过渡到橙红，深酒紫裙 |

每套的围裙右下角都印着同一只喷水小鲸鱼，颜色取这套裙子的深色。

几何全部共用，每套配色只是一组贴图（原版在 `tex/`、`feat/`，其余在 `schemes/<id>/`）。
每套的 `accent` 给睡眠 z、倾听弧线、思考泡泡上色。`figure.setScheme(id)` 切换，
`figure.preload()` 预先载入全部配色（每套服装各一份）后切换是即时的；`setScheme(id, { fade: 秒 })` 在两套之间渐变（`rig.js` 给每个部件加了第二张贴图的混合）。展示页的「配色」一栏就是这个。

## 服装

| id | 服装 |
|---|---|
| `maid` | 女仆装：女仆裙和围裙，围裙右下角印着喷水小鲸鱼（见「配色」） |
| `cape` | 冬装：鲸鱼兜帽（帽顶喷水，两侧鲸鳍）、两根带毛球的系带、毛绒边斗篷、条纹围巾、毛绒袖口和靴子 |

服装是形象包的第二维（`figure.json` 的 `axes` 里的 `outfit`，每个选项带一张全身缩略图 `thumbs/<id>.png`，144×144，DeepSeek 配色站姿，两张同一比例），
和配色连写成 `<配色>-<服装>`，比如 `claude-cape`；只写配色（或预设 id）就是女仆装，8 个预设都是女仆装（`pick.outfit` 为 `maid`）。
`figure.js` 的 `pickOf` 拆开它，哪一段不认识就取那一维的第一项（别的版本存下的服装不会被当成配色名）。
女仆装的部件是 `model.json` 的 `parts`，别的服装在 `model.outfits` 里列出自己的全部部件：没有 `src` 的沿用女仆装的同名贴图，跟着配色换色（头发、脸、尾巴）；
有 `src` 的是这套服装自己的贴图（`outfits/<id>/`），哪套配色都一样。服装可以覆盖枢轴（`pivots`），也可以带挂件（`deformers`）。
换服装要重建部件（`layoutOf`，连同全部姿势的变形器和部件），所以是一帧切换，不渐变；同一套服装里换配色照样渐变。`figure.scheme` 返回 `<配色>-<服装>`。

挂件是钟摆，每个给出枢轴、挂在哪个变形器上和 `gain`：不管头、身体和整组怎么转都保持下垂，被拎起甩动、走路、点头、落地、转脸时荡起来，荡几下停住，站着时轻轻晃。
`gain` 是摆动的自由程度，系带上的毛球是 1，围巾尾巴是 0.5（布只垂一半）。
冬装的部件：兜帽（后层、内衬、前沿、两只鳍、喷水）、两根系带、斗篷、披肩、围巾（领口和前后两条尾巴）、裙子、坐姿下半身、两条腿、两只手臂和远侧袖口前层；头发、脸、五官和尾巴用女仆装的。

姿势图（`model.json` 的 `poses`：趴姿、跪坐、背面、团成球、各个手势的手臂）的女仆装那份在配色的 `tex/` 里，冬装不用它们：一套服装只用自己 `poses` 里列出的画
（`"shared"` 是 `outfits/<id>/poses/<贴图名>.png`，各配色共用，比如只有冬装袖子的手臂；`"scheme"` 是 `outfits/<id>/schemes/<配色>/poses/<贴图名>.png`，
画里有头发、脸或尾巴的整身图每套配色一张，某套没有就用共用的那张），几何和女仆装那张一样（同一个框、枢轴和锚点）。
冬装有全部 37 张手臂（`outfits/cape/poses/arm_*.png`，都是 `"shared"`）：招手、托腮、欢呼、比心、杯子、书、合十、叉腰、张开双手、挠头、竖食指、
茶盘、敬礼、比耶、指、捂嘴、抱臂、屈膝礼、伸懒腰、拍手（合掌和分开）、摊手、抱头、举手、点赞、嘘、擦汗，袖口是带蓝色小蝴蝶结的毛绒袖口，
同一个框和像素尺寸，手的位置不变。女仆装手臂在前臂周围带着的围裙、腰带、围裙蝴蝶结和衬衫都去掉了（那里露出斗篷）；拍手合掌时右边的毛绒袖口收进画框里。
女仆装的袖子按配色换色，垂到头发上时用渐隐收尾看不出来；冬装的袖子各配色都是深蓝，所以伸懒腰只画到袖口（袖子藏在头发后面），
举到脸旁的手臂（招手、欢呼、比耶、捂嘴、嘘）上层那份只留手和袖口，袖子留给侧发下面的那份，抱头的两只袖子不渐隐，末端收成描了边的圆头（像手肘往后弯进头发里）。近侧手臂（z 6）像冬装自己的 `arm_near` 一样压在披肩（6.1）和围巾领口（6.2）下面，
双手的画（9.6）盖在斗篷、披肩和围巾上，和女仆装一样；冬装的 `poseZ` 改了五张：捂嘴和嘘的前臂横过围巾领口，放到 6.25（领口上面、侧发下面），
挠头和敬礼的手臂放到 13.4，盖住兜帽系带的毛球（13.35），不然毛球会从举过头顶那份手（14.2）渐隐的下沿透出来；跪坐混合的下半身见下。
冬装的整身姿势图也都有了（`outfits/cape/schemes/<配色>/poses/`，16 张，都是 `"scheme"`，八套配色各一份）：趴姿（`lie_body`、`lie_tail` 和闭眼、笑嘴、说话嘴贴片）、
跪坐（`kneel_body` 和贴片）、跪坐混合的下半身（`kneel_low`）、背面（`back_body`）、团成球（`roll_ball`），以及跪坐和趴着时实时脸用的空白脸和刘海（`*_blank`、`*_fringe`）。
它们是对女仆装那张（或它的来源图）做「换成冬装」的编辑，按女仆装的框和对齐裁出来，脸、手、尾巴和脚的位置不变；DeepSeek 以外的 7 套配色只按区域换头发、眼睛、皮肤和尾巴的颜色，冬装本身不换色。
几处和女仆装不一样，都在 `model.json` 的 `outfits[1]` 里：
- 趴姿：兜帽的喷水比女仆装的头顶高，`lie_body` 的画布顶上多 4 行（748×477）；女仆装的 `lie_body.png` 也在顶上补了 4 行透明，两套共用同一个框 `[9.6, 105.13, 236.96, 151.03]`。女仆装贴图的每个像素还在原来的位置；只是 32×20 的网格现在铺在更高的框上，趴姿、说话和踢腿各帧沿描边的渲染差不到一个贴图像素（踢腿时最大，0.68）。
- 实时脸：冬装的空白脸和刘海是从冬装自己的图上裁的，框和女仆装的不同，用 `poseParts` 按部件 id 给出（`kneel_blank`、`kneel_fringe`、`lie_blank` 的 `box`）；脸本身的框和五官的摆放（`face.box`、`face.place`）用女仆装的。
- 跪坐混合：`kneelLowHides` 让它多藏起站姿的斗篷和围巾两条尾巴（`kneel_low` 里画了从肩膀往下的整件斗篷），`poseZ` 把 `kneel_low` 放到 5.08（远侧袖口前层 5.1 和近侧手臂下面）。
- 翻滚：球的轮廓多了喷水和远侧兜帽鳍、少了呆毛，`rollSupport` 是按冬装球的贴图算的每 1° 质心高度（360 个，替换 `poses.roll.support`；喷水和鳍尖是尖角，每 5° 一个点时两点之间的直线会让球在翻到约 208° 时浮起 2-3 像素），周长 `around` 仍是 628。
滚动时兜帽系带的毛球只跟 kit 一半的摆动（球里看不见时也一样），弹出来时不会甩到脸上。每个词都照常做（`doWord` 都返回真），穿冬装和穿女仆装时每个词用到的整身图一样。

## 构成

- `web/kit/rig.js`：一个小型的 Live2D 式渲染器。每个部件是一张贴图铺在一个网格上，网格点逐帧经过变形器链：
  `rot` 绕枢轴转动、缩放、平移，`warp` 在一个矩形上加位移场。WebGL2 绘制，拿不到时用 WebGL1。
- `web/whale/figure.js`：模型本身。把 kit 每帧给的数据（腿的角度、坐下程度、视线、眨眼、表情、说话幅度、横向惯性）
  换成变形器参数；后发、刘海、裙摆、尾巴、两只鲸鳍、呆毛、两只手臂各有一个弹簧；眼睛、嘴、腮红每帧画进一张脸部贴图，
  挂在头部的变形器上。画布放在宠物自己的 SVG 组里，舞台的位置、挤压、倾斜、转身照常作用。
- `web/whale/model.json`、`tex/`、`feat/`、`schemes/`：部件的位置（桌宠坐标，x=128 在身体下方，鞋底 y=256）、枢轴、贴图和五官贴图。

部件（女仆装）：尾巴、后发、远侧手臂、两条腿、上身、站姿裙子、坐姿下半身、近侧手臂、远侧鲸鳍、脸、近侧鲸鳍、头侧蝴蝶结、刘海（含两侧垂发）、头饰、呆毛；冬装的见「服装」。

坐下时下半身换成单独画的一张坐姿图（裙摆摊在地上、两腿向前伸、两只鞋都露出来）：身体下沉到一半时，
站姿的裙子和腿在两三帧内换成它，同时身体压扁一下；站起来是反过来。
头部转动靠视差：刘海和呆毛位移最大，脸、五官和近侧鳍其次，后发和远侧鳍反向移动。
常态眼睛直接从母版上按颜色拆成睫毛、眼白、虹膜三层（眼白在虹膜下面的部分用周围的白色延伸补齐）：眨眼时眼睑沿拟合的眼睑线下压并裁掉上方，视线移动只移虹膜。
开心、睡着、被拎、喜欢、晕、惊讶这几种眼睛和嘴是整张替换的贴图；生气和难过把眼睑向内侧压斜，嘴是画出来的下弯线。
其余表情复用这些贴图再加程序绘制：慌张用被拎时的 > < 眼，害怕用惊讶的眼睛，嘟嘴是缩小的 O 形嘴，
期待在虹膜上画白色星形高光，大哭在脸颊上画两道泪痕，疑惑把远侧眉毛单独抬高、头顶加问号，
嫌弃在刘海上画三道带浅色描边的黑线（深色头发上也看得清）。温柔是半垂的眼加浅浅的小弧嘴、内端稍抬的眉，头歪着，每 2.2 秒慢慢点一下头（`lean`，一次 3.2 秒的表情里点两下）；尴尬是笑眼配八字眉、一大滴汗、一道又宽又平的嘴（`MOUTH` 里 `[形状, 宽度]` 两个数字的写法），身子和头往后缩一点；偷笑是笑眼往旁边低一点看，每 1.6 秒憋不住抖一阵：`FACES` 给出 `titter`（0 到 1），她的上身绕腰压一压、脖子往下一点、鳍和呆毛跟着颤，Coo 是圆环一压一压。感动是含泪的笑：圆眼配八字眉、虹膜上的星光、笑嘴，泪痕画得又细又短又淡（`streams` 可以是 `{ a, len, w }`），每 1.5 秒掉一颗泪（`emitEvery`）。石化先愣住（惊讶的眼、黑线），约 0.3 秒起 `freeze` 为真：她就停在那一帧，只重画上一帧的姿势，不眨眼、视线不动、不随说话张嘴；`stone`（0 到 1）让 rig 的着色器把所有部件一起褪成灰白（`st.stone`，趴姿、背面、团成球都管用），1.1 秒起从头顶往下长出一道裂纹（SVG，`crack`），同时整组一抖、掉几块碎石（`chip` 粒子），表情结束前 0.6 秒解冻、颜色流回来。害羞、紧张、温柔、偷笑、石化的视线和头会随时间变化（`FACES` 的 `f(t, pet)` 按 `pet.exprAt` 计时）。
难过时尾巴慢慢垂下（`MOOD` 的第三个值是垂尾幅度），回来时较快；每只鲸鳍有自己的抖动节奏：生气是一起嗡嗡震，慌张是不规则地抖，期待是一阵一阵扑。
`HEAD_PITCH` 的正值是低头（五官下移、头顶露出更多），往下看、睡觉、难过、大哭都是正值。
kit 为 Coo 设计的整组倾斜（倾听、点头、打瞌睡、晕乎乎时整个圆身体歪过去）在她身上换成低头、歪头，脚不离地；
只有腾空、被拎着、起跳下蹲和落地时整组倾斜，跑步保留一半前倾，跳舞的摇摆六成给整组。
跑步是火影跑：两只手臂一起甩到身后，整组再多前倾 14°（从脚底整个身体一条线前倾，不在腰部弯折，否则衣身会和裙子、腰后蝴蝶结错开），头往回抬一些；远侧袖口的前层（`arm_far_end_front`）在手臂甩到身后时隐去。
腿绕髋部摆动、抬脚（`hinge`），但灯笼裤的上沿不跟着动：转动和抬起都从髋部往下才生效，否则裤腰会从裙子窄窄的腰口两侧和上方露出来；走路时往后的那只脚稍微抬高一点，像蹬地时脚跟离地。
近侧（画面左边）的腿是 `leg_back`，图层在远侧的 `leg_front` 上面；远侧那条腿的贴图删掉了平时只被远侧手臂挡住的裤腰一角，手臂甩开时那里不会露出来。
点头、摇头、歪头、招手、鞠躬由她自己画：点头是低头两下，摇头是脸左右转，歪头是好奇地把头歪向一边（她的脸本来往哪边歪就往哪边，不歪的往前），停约 1.2 秒再回正（点头、摇头、叹气、歪头按 `frame.head` 自己的进度画，和招手这类手上的动作可以同时；没有 `frame.head` 的 kit 照旧从 `frame.gesture` 取），招手把近侧手臂举到肩高挥动（远侧手臂举起来会被身体和头发挡住），
鞠躬时上身（衣身、两只手臂和头）绕腰部枢轴 `waist` 前倾，裙子和腿不动；探头前倾一半，后缩时往后仰、手臂收紧。
低头（`droop`，1.8 秒）是头部通道的动作：脖子往前弯、脸往下（`angleY`）、眼睛往下看，停住再抬起来，被别的头部动作打断时几帧内回正（`tiltEased`）。
凑近（`closer`）时上身连头整个变大一点（`waist` 缩放，像离你近了），后仰（`leanback`）时上身往后仰、变小一点、下巴抬起来，
晃来晃去（`sway`）时整个身子绕脚左右晃三下、头跟着晃；这三个都是 kit 交给她自己画的（列在 `gestures` 里），站着、坐着都能做。
跺脚（`stamp`）和眨眨眼（`blink`）由 kit 做：跺脚时 kit 抬起前面那只脚、使劲落下两次（`STAMP`，落地声、扬尘、整组一震），她的腿照 `frame.legs` 画；眨眨眼是 kit 连着给三次 `frame.blink`（相隔 0.25 秒，平时自己偶尔也会连眨两下，三下才看得出是故意的）。
摇尾巴（`wag`，2.4 秒）走 kit 给尾巴、耳朵、翅膀单开的通道（`frame.appendages.tail`），和头部、手上的动作同时做：她的尾巴照心情摆动的那部分换成摇尾巴自己的（左右 26°，比期待时的 13° 大一倍、也更快，用自己的相位，摇完几帧内交还给心情），站着、坐着摇身后的尾巴，趴着摇地上的尾巴（`lieTail`），背影摇背影图上的尾鳍；跪坐时尾巴是跪坐图上画好的，不动。发抖、扑腾在 kit 的动作之外加上收紧手臂、垂下鲸鳍，或鲸鳍、尾巴、呆毛一起扑动。

## 写一个形象包

大肥鱼也是照这份说明做的，可以直接拿她当模板。

**目录**：根上一个 `figure.json`，加上它引用的脚本、贴图和音频。放进数据目录的 `figures/<目录>/`（或应用给的 `packRoots`）就会被扫到；
字段的完整说明和校验规则在包的 README「形象包」一节和 `src/packs.ts`。

**词表**（`vocab`）：这个身体在场时 bot 能用的全部表情和动作，没列的词 bot 用不了。每个词写清 `names`（bot 可以用哪些名字写它）、
`about`（在这个身体上是什么样子，原样进 bot 的提示词），`seconds`（连着做时等多久再做下一个）。
用 kit 的包可以直接列 kit 会做的词（`KIT_EXPRESSIONS`、`KIT_MOTIONS`），也可以只列一部分；Coo 还列了 kit 的扩展词（见下一节，包括 30 个组合表情），一共 107 个；大肥鱼在这些之外多一个托腮（`muse`）和六个头部、身体的动作（低头 `droop`、眨眨眼 `blink`、凑近 `closer`、后仰 `leanback`、晃来晃去 `sway`、跺脚 `stamp`），还有摇尾巴（`wag`）和七个新画的手势（拍手 `clap`、摊手 `shrug`、抱头 `headhold`、举手 `raise`、点赞 `thumbs`、嘘 `shush`、擦汗 `wipe`），一共 122 个；四个娘（Claude 娘、GPT 娘、Gemini 娘、Grok 娘）也列了扩展词、这六个动作和七个手势，没有喷水（`spout`），但有托腮和加油（`fist`）、记笔记（`jot`）、对手指（`twiddle`），Claude 娘一共 123 个；GPT 娘再多摇尾巴、扇翅膀（`wingbeat`），125 个；Gemini 娘再多摇尾巴、抖耳朵（`earflick`）、竖耳朵（`earsup`）、耳朵耷拉（`earsdown`），127 个；Grok 娘再多扇翅膀，124 个。

**表情对**（`pairs`，可省）：bot 在同一组里写两个表情（`【开心+惊讶】`）时，默认拆成先后两个。想让它们合成一张脸，就在 `pairs` 里列出这一对：
`"happy+surprised": "surprised+happy"` 是合成，值里给眼的那个在前、给嘴的在后（键里先后无所谓）；`"happy+smug": "smirk"` 是别名，显示成词表里另一个表情。
World 只合并列出的对，合成对一律按值的方向发给身体（眼在前，不管 bot 先写哪个），回执告诉 bot 谁给了眼、谁给了嘴。
带 `plus` 的 kit 身体（`doGroup`）把一组里收到的前两个表情合成「第一个的眼 + 第二个的嘴」，所以 `pairs` 写的方向就是显示出来的样子，不用另配表；
别的身体只列别名对，或者自己的 `doAll` 也照这个顺序合成——不会合成的身体收到合成对时后一个表情胜出。校验规则见包的 README。
内置形象各列了自己看过渲染图挑出来的对（四个娘 135 对、大肥鱼 106、Coo 24）；导出的包不带 `pairs`（上游的 World 不合并）。

**入口**：`figure.json` 的 `entry` 和 `export` 指向一个工厂，按 `factory(base, { model, scheme, kit, loadImage, asset, host })` 调用，
在沙箱里返回一个身体。契约在 `web/figure-frame.js` 开头。最省事的写法是交给 kit：

```js
export async function createMyBody(base, opts) {
  const figure = await createMyFigure(base, opts);   // 只管画
  return opts.kit.createBody(opts.host, { figure, words: {
    facepalm: { expression: { like: 'worried', sound: 'sigh' } },   // kit 没有的表情：眼神、汗滴借 worried 的
    salute: { motion: { seconds: 1.5, face: 'happy', sound: 'clack' } },   // kit 没有的动作：由 figure 按 frame.gesture 画
  } });
}
```

**figure**：`draw(petG, face, frame)` 每帧调用一次，把这一帧画进 `petG`（逻辑坐标，身体在 256×256 的方格里，x=128 在身体下方，脚底 y=256）。
`face` 是 kit 的表情参数（眼睛形状、腮红、头顶符号等，见 `FACES`），`frame` 带表情名（`frame.face`，包自己的词就是词的 id）、模式、模式时长、
说话幅度、困意、坐下程度、朝向、视线、腿和正在做的短手势 `frame.gesture`（`{ kind, k }`，`k` 从 0 到 1，没有时为 `null`）。
可选的字段：`anchors`（视线原点、泪滴，`tears` 是大哭时两只眼睛下各自的起点、睡眠 z、爱心、气泡的位置）、
`extent`（身体的框）、`hits`（接收鼠标的圆）、`gestures`（自己画、kit 不再整组倾斜的手势）、`groupTilt(mode, tilt, lean)`（整组转多少度）、
`colors.z`（睡眠 z 和音符的颜色）、`setScheme(id, { fade, at })`（换打扮）、`setSkin(skin)`、`dispose()`。坐标都是逻辑单位，每帧都会重新读，可以写成 getter。

**音效**：`figure.json` 的 `sounds` 声明包里的音频文件和它的类别（`move` `touch` `face` `snore`）。身体按名字要声音，
桌宠页播放，设置里按类别关掉的那一类连包的声音一起静音。和桌宠内置音色同名的声音会替换掉内置的那个，比如包里的 `jump`。

**沙箱**：包的脚本跑在不透明源的 iframe 里，连不了网络，图片要用 `opts.loadImage` 载入（WebGL 才读得了），
别的文件用 `opts.asset(路径)` 拿地址。身体报告的框会被限制在 kit 能拉伸到的大小以内，互动事件只在真实的鼠标输入之后才算数。

**不用 kit**：工厂也可以自己实现 `step`、`layout`、`do` 等方法，身体怎么动全由包决定；会飞的、不走路的、3D 的都可以这样做。
`layout()` 要报告的字段见 kit 的 `layout`。

## kit 的扩展（`plus`）

Coo、大肥鱼和四个娘（Claude 娘、GPT 娘、Gemini 娘、Grok 娘）用的 kit 比原版多一些词、表情和姿势，只在打开 `plus` 时才有：`createPet(els, { …, plus: true })`、
`createBody(host, { figure, plus: true })`。不开时 kit 和原版的 kit 行为完全一样（只认 `KIT_EXPRESSIONS`、`KIT_MOTIONS` 和包自己的 `words`，
表情用原版的 `FACES`），所以照上面写的形象包在这里照常能用。打开后：

- 多出的词：`PLUS_EXPRESSIONS`（43 个表情）和 `PLUS_MOTIONS`（49 个动作；尾巴、耳朵、翅膀的五个（`APPENDAGE_MOVES`）kit 自己不画，只有长着它们的形象才列；其中 `muse`、`fist`、`jot`、`twiddle` 四个手势和 `clap`、`shrug`、`headhold`、`raise`、`thumbs`、`shush`、`wipe` 七个手势只有画了那几张手臂图的形象才看得出来，kit 自己不画（拍手的四声轻响是 kit 的，按 `CLAP.at` 在两手合上时响），所以 Coo 不列；低头、眨眨眼、凑近、后仰、晃来晃去、跺脚六个 kit 在 Coo 身上也能做（整个圆环前倾、后仰、左右晃，眨眼、抬脚是 kit 自己的），但 Coo 的词表没有列），扩展的表情参数在 `PLUS_FACES`（害羞、难过两个表情也换成了它的）。
  43 个表情里有 30 个是组合表情（`PLUS_MIXES`，由 `mixFace` 拼成 `PLUS_MIX_FACES`）：眼睛取一种表情的，嘴取另一种的，眉、身体语言和符号可以另指；
  其中六个带 kit 自己画的特效（`MARK_FX_KEYS` 和 `orbit`）：气炸 `fume` 头两边冒白烟、心碎 `heartbreak` 一颗心裂成两半掉下去、撒花 `confetti` 撒出彩色纸屑、郁闷 `cloud` 头旁边一朵下雨的小乌云、无言以对 `dots` 一个点一个点地冒出「……」，画在 kit 的粒子层里（位置按 `anchors` 的 `bubble`、`glints`、`bulb`，趴着时按 `anchors.lie`），形象不用管；眼冒金星的 `orbit` 是晕的小星星，由形象自己画（同晕）；
  脸对象带 `parts: { eyes, brows, mouth, body }`（kit 的表情名），画了五官的形象按部位查自己的表，没有 `parts` 时都按 `frame.face` 查。
  找词的顺序是 kit 的词、包的 `words`、扩展词，所以包自己的同名词（比如上面例子里的 `salute`）优先。
- `frame` 多带 `lie`、`prone`（趴下）、`kneel`（跪坐）、`talkShape`（说话口型 0–3）、`away`（背过身的程度）；不开 `plus` 时它们都是 0 或 false。
  还多一个 `head`（`{ kind, k }` 或 `null`）：点头、摇头、叹气、歪头、低头、眨眨眼（`HEAD_GESTURES`）走头部自己的通道，和 `frame.gesture` 里的手势同时播、各有各的进度；不开 `plus` 时没有这个字段，它们照旧作为 `frame.gesture` 送来。
  再多一个 `appendages`（`{ tail, ears, wings }`，各是 `{ kind, k }` 或 `null`）：摇尾巴、抖耳朵、竖耳朵、耳朵耷拉、扇翅膀（`APPENDAGE_MOVES`）各走自己那个部位的通道，不带表情、不换模式（走着照走、跪着照跪），由长着那个部位的形象自己画、盖过心情给那个部位的动作；不开 `plus` 时没有这个字段。
- 表情的规则：主动要的表情（词或 `setExpr`）不会被后面的动作清掉（石化遇到任何动作都解除，睡觉也清掉），动作自带的脸等它到期后再接着显示；
  被拎、晕、起身、倾听、睡着盖住时它暂停倒计时，连续盖住超过 5 秒才丢掉；唱歌、叹气、看书这类「脸就是身体」的手势遇到主动要的表情时，
  脸名是 `表情+嘴+动作脸`（如 `angry+singing+singing`），眼睛是表情的，身体语言（和唱歌、叹气的嘴）是手势的。
- `doGroup(words)` / 身体的 `doAll(words)`：一组词在同一帧里做（姿势、手势、头部手势、起跳、表情的顺序），做不了的立刻报 `done`。
  组里的前两个表情（`neutral`、`petrify` 除外）合成一张主动要的脸，脸名 `眼+嘴`：第一个的眼（连同眉、身体语言和符号），第二个的嘴；再往后的表情先做，被它盖住。
  音色、星光、弹跳跟眼那张脸（眼那张没有音色时用嘴那张的），任一个是 sleepy 时持续 4.4 秒，否则 3.2 秒。
  组里的表情至少持续到同组手势自带的脸结束（唱歌、看书、喝茶、跳舞），手势末尾不会换回它自己的脸。
- figure 可以声明的能力：`poses`（`lie`、`back`，随帧报告）、`anchors` 里的 `lie`、`glints`（开心、得意时星光冒出的几处，没给就在气泡位置两侧）、`spout`、`kneelRaise`、`tears`、`kneelArms`（跪坐时也画得出手势，`ARM_GESTURES` 里的手势就不结束跪坐；大肥鱼和四位娘有 `poses.kneelLow` 时声明，World 那边靠包里 `kneel` 词的 `keepsArms` 把它们和跪坐分到同一组），
  以及在 `gestures` 里列出自己画的扩展手势；Coo 专用的几项由 `cooFigure()` 声明。每一项的说明在 `web/kit/body.js` 里 `createPet` 的注释。
- `talk(ch)` 可以带上正在说的字，口型由字的编码决定；不带时每说一下换下一个口型。
- 带 `plus` 的身体做不了的词（不认识的，或此刻做不了的，比如倾听时唱歌）`do(word)` 会立刻报 `done`，页面的动作队列不用干等；不带 `plus` 的身体和上游一样，等满这个词的 `seconds`。
- 声音一律按 `play(名字, 类别)` 要，扩展的音色在 `web/sound.js`，只有内置的六个形象（`web/sound.js` 的 `OWN_PACKS`）听得到（别的包要这些名字和在上游一样没有声音，得自带音频文件）；唱歌被打断时要 `stop:song`，不认识它的页面忽略就是。

大肥鱼的入口 `createWhaleBody` 不用 `opts.kit`，而是由 `figure.js` 自己 import 旁边的 `../kit/body.js`，并传 `plus: true`。
在应用里它和 `opts.kit` 是同一个模块；导出成形象包时把 `whale/figure.js` 和 `kit/body.js`、`kit/rig.js` 放在一起，包就带着自己的 kit，
在原版的桌宠里也是同样的词和姿势。`figure.js` 不联网（形象包的沙箱也不让）：`model.json` 由调用方读好传进 `opts.model`，
没给就直接报错；贴图都经 `opts.loadImage` 载入。`kit/rig.js` 比原版多一个 `st.stone`（0 到 1，整张褪成灰白的石头色，石化用）。
展示页（`serve.mjs`）同样用 `plus: true`，按 `figure.json` 的词表给每个词一个按钮。

下面是这些扩展在大肥鱼（和 Coo）身上的样子。

背过身（`away`）也作为 `frame.gesture` 送来（约 3.2 秒，`k` 前约 0.25 转过去、后约 0.2 转回来），朝向 `facing` 不变；Coo 没有背影，是把五官淡出再淡入（嘴那道缺口也收回平常大小，背着身不嘟嘴、不随说话开合）；
不在 `figure.gestures` 里列 `away` 的模型没有自己的样子，就整组转去朝另一边，过一会儿再转回来（`frame.facing` 跟着转）。
趴着（`poses.lie` 不为 `false`、画得出趴姿）时不送这个手势，只换成嘟嘴的脸，做到一半趴下也就此停下；画不出趴姿、照坐着画时照常送。
`figure.poses.back === true`（和 `poses.lie` 一样随帧报告）表示模型画得出自己的背影：转身时整组的水平缩放不再压到接近 0，
最窄到 85%，过中点直接翻面，`frame.facing`（-1 到 1，照旧是转到哪儿的原值）告诉模型转到了哪一步，由它自己画中间的样子。
趴下（`lie`）是坐下之后再趴：`frame.sit` 全程保持 1，`frame.lie` 从 0 到 1 是趴下的程度，`frame.prone` 表示这次休息是趴着的（趴着睡、从趴着起身时也是）。
趴着时偶尔的小动作（踢脚 `kick`、托下巴 `chin`、尾巴拍地 `thump`）作为 `frame.gesture` 送来，kit 自己不做任何处理。
`anchors.lie` 给出趴着时的同一组点，外加点击椭圆 `hit` 和半宽 `halfW`；没有它时 kit 按坐着处理点击、气泡和屏幕边缘，
`figure.poses.lie === false`（当前配色缺趴姿贴图）时也一样。所以不认识 `lie` 的模型照样能用：她只是一直坐着。
招手时，握拳的近侧手臂先往上抬，转过 70–95° 时（按手臂实际转到的角度，不按手势的时间）换成张开手的那张画（`poses.wave.rest` 是普通手臂转到多少度时与它指向一致），
它接着抬到位，手绕手腕挥动；趴着时不换。缺这两张图的配色照旧用握拳挥手。
比心（`heart`）时两条握拳的手臂先往胸前收，随即换成双手在胸前比心的那张画，从稍低处升到位，跟着节奏轻轻颠，眼睛换成爱心眼并冒爱心。
欢呼（`cheer`）时两条握拳的手臂先往上抬（近侧到 80°、远侧到 60°），在差约 15° 时（同样按手臂实际转到的角度，几乎是直接切换）各自换成举着张开手的那张画，
两者交接时指向一致，之后画的手臂接着抬到自己的角度（`poses.cheer.arms.*.rest`），跟着节奏上下晃；放下时倒过来，随握拳手臂的角度收回、在同一段角度交回。
缺这些图的配色照旧用握拳的手臂往上甩。
做「思考」表情或托腮（`muse`，任何表情下都行，手势做完就放下）、站着或坐着时，远侧手臂换成托腮的那张画：前臂绕肘部从下往上抬到下巴，抬到一半时和原来的远侧手臂交接；
它挂在脖子上，头动时手不离开下巴，思考时原本的歪头也收小。要用到远侧手臂的手势（欢呼、比心、喝茶、看书、拜托、叉腰、抱抱、翻滚、发抖、扑腾、后缩、探头）一开始她就把手放下，
托腮的前臂也只在欢呼、比心那几张画没盖住远侧手臂的地方出现。缺这张图的配色照旧不托腮。
托腮和比心的 `wrist` 是画里手所在的位置（测试按贴图的皮肤像素核对），它们不用 `rest`。
喝茶（`sip`，约 3.6 秒）和看书（`read`，约 4.4 秒）同比心一样：两条握拳的手臂往胸前收，随即换成双手捧着杯子（`poses.cup`）或翻开的书（`poses.book`）的那张画。
画的上半（手和杯子）挂在一个网格变形上：喝的那一下（`k` 约 0.38–0.66）抬到下巴，袖子跟着拉长，kit 同时让她闭眼、低一点头；杯口冒三缕热气（SVG，`wrist` 是杯口）。
看书时低头、眼皮半垂，视线沿一行字从左扫到右再回到行首。道具在各配色里颜色不变。Coo 没有手，用两只圆爪捧着自己画的杯子或书（书隔一会儿翻一页）。
翻滚（`roll`，约 1.5 秒）时 kit 让整组沿朝向走滚一圈的路（`ROLL_D`，半径 100 的球的周长；前面地方不够、后面更宽时先转身），
`k` 约 0.2–0.8 之间按 `rollTurn(k)` 缓入缓出地转一圈；滚的时候 `busy()` 为真，后面的动作等她站起来再做。Coo 是整个圆环绕环心转，
往下落到环底贴地、脚收起来；列了 `roll` 的模型自己画，没列的就沿路跳一下。靠近屏幕边缘时路不到 `ROLL_D`：`frame.gesture.travel` 是这次实际滚的距离
（逻辑单位，朝前为正，不会是负数），自己画球的模型只转 `travel / 周长` 圈，才不会在原地打滑；没有 `travel` 的 kit（原版）一律按 `ROLL_D` 算。
Coo 的圆环还是转满一圈好站正，路不够的那部分转在半空里（离地跳起，高度按差多少算），贴着地的时候转多少就走多少。
大肥鱼蹲下，在 `k` 约 0.13–0.165 换成一张团成球的画（`poses.roll`），
它绕质心转（`ballAngle(k, 周长, travel)`），`support` 是每转 5° 时质心到最低点的距离，按它抬高放低，球总贴着地面；约 0.835–0.87 换回站姿弹起来。缺这张图的配色也沿路跳一下。
喷水（`spout`，约 1.6 秒）由 kit 画，任何模型都一样：先蹲一下，`k` 约 0.25 起从 `anchors.spout`（没给就在 `bubble` 下面一点；趴着用 `anchors.lie.spout`）
往上喷出一根水柱，到 0.45 前后散开，水珠（`spray` 粒子，圆珠带高光，和眼泪的形状分开）按重力落回地面；水用固定的蓝白色，不跟配色走。
大肥鱼自己画蹲和弹起、鲸鳍张开扑动、呆毛被顶起来、尾巴一甩；她的喷水点在呆毛后面的头顶，趴着时在趴姿头顶。
拜托（`pray`）、叉腰（`hips`）、抱抱（`hug`）和喝茶、看书一样，是一张两条前臂一起画的图（`poses.pray` / `.hips` / `.hug`），按比心的方式交接：
拜托时合十的手跟着节奏一下一下往上拜，脸是 `pleading`（亮晶晶地往上看）；叉腰沿用她当时的表情（生气、得意、认真），没有就一脸认真；抱抱时双臂微微摆开，脸是温柔。
挠头（`scratch`）和有了（`idea`）举起的是近侧手臂，按欢呼的方式交接：握拳手臂先抬到 80°，差约 15° 时换成画的那张，画的手臂再抬到自己的角度（`rest`），
同样画两份（整条手臂在原手臂的层、手和小臂再画一份在头部之上）。挠头时手在头侧一下一下地挠；有了的那张是弯着的手臂（手比握拳手臂短得多），所以不按角度交接，而是像比心那样：握拳手臂往胸前收，画的手臂从稍低处升到位；食指往上一戳，kit 在头的前上方冒一个亮起来的灯泡（`bulb` 粒子，任何模型都有，避开头顶的对话气泡）。
撒娇（`coax`）是表情：笑眼、满脸通红，嘴换成画出来的 ω 猫嘴（`cat`，说话时 ω 下面张开一个小口），整个人左右摇（`rock`，kit 给整组的倾斜，
她自己的身体也绕脚底摇），双手收在身前，每 1.2 秒冒一颗小心心（`emitEvery`）。
唱歌（`song`，约 4 秒）由 kit 画一圈圈往外扩的声波弧线（`wave` 粒子，倾听弧线反过来）和往上飘的音符，任何模型都有；
脸 `singing` 是闭眼的笑眼、微微抬头，嘴按节拍开合（`sing`），大肥鱼的两只鳍跟着打拍子；有人开始说话（倾听）时歌就停，倾听中也不唱。
奉茶（`serve`）和喝茶一样是一张两手托着托盘的画（`poses.tea`），托盘往前递时整张稍微放大一点，杯口冒热气。
敬礼（`salute`）和比耶（`vsign`）举起的是近侧手臂，都是弯着的手臂，按有了的方式进来；敬礼是「啪」地一下到位，稍微冲过头再弹回，
之后完全定住，放下也快；脸 `saluting` 举手时一脸认真，放下时眨眼。比耶时歪一下头、眨眼，头旁闪一下星光。
指（`point`）举起的是远侧手臂（`FAR_RAISES`），朝她面向的方向伸直，按欢呼的方式按角度交接（远侧手臂转角为负），袖根往肩膀方向渐隐（贴图做时的 `fade_root`），压在头发上也不露切口；脸 `pointing` 盯着前方。
捂嘴笑（`cover`）是弯着的近侧手臂，挂在脖子上（`NECK_RAISES`），头一抖手也跟着，不会离开嘴；脸是偷笑。
举手（`raise`）是伸直的近侧手臂，按挠头的方式按角度交接，举过头顶的手轻轻晃；点赞（`thumbs`）、嘘（`shush`）、擦汗（`wipe`）是弯着的近侧手臂，按有了的方式进来，
嘘和擦汗也挂在脖子上（`NECK_RAISES`），擦汗时手腕在额前抹一下；拍手（`clap`）、摊手（`shrug`）、抱头（`headhold`）是两条前臂一起画的图，抱头的那张挂在脖子上（`NECK_HANDS`），
点头、摇头时手不离开头；拍手有合掌和分开两张画（`ARM_TWIN`），按 kit 的 `clapShut(k)` 一帧切换，绝不两张同时露出来，先分开、合上四次、最后分开放下。
抱臂（`cross`）、伸懒腰（`stretch`）、屈膝礼（`curtsy`）都是两条前臂一起画的图：抱臂和叉腰一样沿用当时的表情，没有就嘟嘴；
伸懒腰时握拳手臂先往上举再换成十指相扣举过头顶的那张（袖子盖在刘海上、往下渐隐），身子拉长、仰头、闭眼打哈欠；
伸懒腰按手臂转到的角度交接（握拳手臂过 70–95° 才换），那张画比画的位置稍微往上一点，手在头饰上方；
屈膝礼时双手捏着裙边，裙摆向两边撑开、下摆两角翘起，身子往下一沉、上身前倾低头、闭眼；坐着时先站起来。
说话时 kit 按每个字给出一个口型编号（`frame.talkShape`，0–3，由字的编码决定，和读音无关），大肥鱼按它把同一张嘴画成张大、扁宽、窄圆、小口四种样子，说话不再只是一张一合；打哈欠的嘴不受影响。
吐舌（`tongue`）是表情：一只眼眨着，嘴边吐出一点舌尖（画出来的，`tongue`）。
趴着时，说话会换上张嘴的贴片（随说话一开一合）、笑的表情换上笑嘴的贴片（`poses.lie.overlays` 的 `talk`、`smile`，和闭眼贴片一样是对趴姿图只改嘴那一块的编辑，嘴里的红色在各配色里不变），睡着、石化时不张嘴。
跪坐（`kneel`）对身体来说是坐下（`frame.sit`），另外带 `frame.kneel`；大肥鱼坐稳后换成一张跪坐的画（`poses.kneel`），站姿在它完全不透明后才隐去，和趴下一样；
眨眼、打盹、闭眼的表情用它的闭眼贴片，说话、笑用它的嘴贴片（同趴姿）。换表情、点头、摇头、叹气、歪头、低头、眨眨眼和摇尾巴不结束跪坐：头挂在跪坐图上的一个网格变形 `kneelHead`（`poses.kneel.head` 框）上，点头往下沉、摇头横向滑、叹气随呼吸起落、歪头绕下巴转约 9°、低头像点头那样往下沉住，框的两侧和下沿不动；下一个手上或全身的动作才结束跪坐、回到普通坐姿。有 `poses.kneelLow`（从跪坐图里裁出的下半身：裙摆、腿和尾鳍，去掉了手臂）时她声明 `kneelArms`，手上的动作不结束跪坐：做手势（或托腮）时跪坐图一帧换成「上半身是站姿那套会动的身体、抬到跪坐图的头的高度，下半身是 kneelLow」，手放下 0.25 秒后再一帧换回跪坐图；唱歌、喷水仍画在跪坐图上。跪坐时头比坐姿高，`anchors.kneelRaise` 告诉 kit 头上的点（气泡、眼泪、星光等）少往下沉多少。Coo 没有跪坐的样子，就坐着。
叹气（`sigh`，约 2 秒）：前 0.35 先吸一口气（眼睛睁大往上看，上身挺一点），之后长长呼出来：半闭眼、八字眉、嘴是小小的「哈」（脸的 `puff`），
上身和头往前一塌，鲸鳍和尾巴垂下，嘴前飘出两小团白气。脸 `sighing` 按 kit 的头部通道（`frame.head`；没有它的 kit 是 `pulse`）计时，叹气被别的动作打断就回到平常的脸。
转身和转圈转到侧对你的那一下（`facing` 绝对值小于约 0.45），以及背过身（`away`）时，换成背面那张画；站着时才有（坐着、趴着照旧），
所以 `poses.back` 只在站着且当前配色有这张图时为真。背过身时她先往中间一挤，在最窄的那一刻正背面交换，转回来也一样；
没有背面图（坐着、缺图的配色）时只把脸转开、低一点头。
大肥鱼趴下时换成一张专门画的趴姿，不是骨架摆出来的：它在坐姿上淡入，等它完全不透明了坐姿才消失，起身时倒过来，所以两者不会互相透出来。
趴姿自己有几个变形：呼吸时背起伏，头绕托着它的下巴点头、摇头、歪头、低头、探头，两只翘起的脚绕膝盖轮流踢（随心情快慢，睡着和倾听时不踢），
尾巴摆、垂、拍地；眨眼、打盹、睡着和闭眼的表情用闭眼贴片，其余表情靠头顶的符号和身体的动静。哪套配色缺趴姿的任一文件，
这套配色照常加载，只是 `figure.poses.lie` 为 false，她趴下时一直坐着。

## 贴图来源

全部由 ChatGPT 生成（角色原设「溟月」，上善无形；DeepSeek 女仆二创，ZipZipPipe），围裙上的小鲸鱼除外。
先定一张侧身二头身的母版立绘，之后所有分件都是对这张母版做「去掉某部分、补画下面」的编辑：去头、去手臂、去尾巴、去裙子露腿、

远侧手臂、脸后面的后脑勺头发、两只手臂切口的描线是把遮罩涂成品红色交给 ChatGPT 只在遮罩里重画的。

按部件在母版里露出的像素学出「原色 → 新色」的对应（颜色和位置上的近邻），再套到这个部件的全部像素上，
包括被遮住的部分。配色表是和 ChatGPT（Pro）一起定的。

- 团成球：按「同一个角色在前滚翻中团成一个圆球、从侧面看、往右滚」生成，从四张里挑一张。它不和站姿配准，

## 展示页

`examples/whale/index.html`，浏览全部内置形象的全部表情和动作。舞台在上（宽屏时在左），面板在下（宽屏时在右），面板太长时自己滚动，舞台一直看得见。

- 「形象」：大肥鱼、Claude 娘、GPT 娘、Gemini 娘、Grok 娘、Coo，点了带着 `?figure=<id>` 重新载入（大肥鱼不带参数）；页面标题跟着换。
- 「配色」：只在有不止一套配色的形象上出现，切换后网址带上 `?scheme=<id>`（大肥鱼是 `<配色>-<服装>`），刷新还是这套；换形象时去掉。换配色保留当前服装，渐变。
- 「服装」：只在有不止一套服装的形象上出现（大肥鱼：女仆装、冬装），保留当前配色，一帧切换。
- 「交互」：说话、倾听、思考、自由活动、抛起来（kit 的被拎起的脸，不算词表里的词）、大小、切换深浅。
- 「组合」：输入几个词用 `+` 连起来（中文名或 id，如 `开心+招手+点头`），回车或「一起做」当一组做（`ctl.doGroup`）。
  组里的顺序和 World 发来的一样（身体、站姿在前，然后手、头，表情最后）；两个表情在 `pairs` 里时眼睛那个在前，或换成它对应的那个词；
  App 里会被拆成先后几组的（占同一部位的词、不在 `pairs` 里的两个表情）照样一起交给 kit，舞台左上角写明。
- 「表情」：按 bot 提示里的心情分组（`src/script.ts` 的 `MOODS`），虚线框是合成脸（kit 的 `PLUS_MIXES`，一张脸的眼睛配另一张的嘴）。
- 「动作」：按部位分组（头 / 尾巴、耳朵、翅膀 / 手 / 手,要站着或坐着不动 / 身，`src/script.ts` 的 `CHANNELS`、`partOf`），角标是这个动作还占的部位。
- 「表情对」：`figure.json` 的 `pairs`，按先列出的那个表情分行；`甲+乙` 是合成的脸（甲的眼睛、乙的嘴，点了按这个顺序 `doGroup`），
  虚线框的 `甲+乙=名` 是直接显示成那个表情（点了做那个词）。

每个按钮显示第一个中文名，鼠标停上去看 id、全部名字和说明（合成脸、`=甲+乙`、也占的部位、大约几秒）。每组和每栏标着个数，面板上方写着这个形象一共几个词。
分组用的数据是 `src/script.ts` 的 TypeScript，页面读不了，所以在页面里抄了一份（`MOODS`、`CHANNELS`、`partOf` 等，注释指回原处），改那边时这里一起改。
脚本驱动页面时可以用 `window.ctl`、`window.figure` 和 `window.combo('开心+招手')`。
