# 鲸鱼娘桌宠

B 站 DeepSeek 二创里的蓝发鲸鱼女仆，做成 Coo 的另一个身体。二头身（头顶到下巴 = 下巴到鞋底），和 Coo 一样侧身朝右站，转身时整组水平镜像。
动作仍由 `pet-core.js` 的 `createPet` 驱动：走、跑、跳、坐、睡、被拎起、甩出去、全部表情、倾听、思考、说话口型都照原样触发。

在本包目录运行 `node examples/whale/serve.mjs`，打开终端输出的地址（默认端口 4318）。
真实桌宠里在装扮页（`/dress`）最上面一行「形象」选「DeepSeek 大肥鱼」，配色在下面一行；选择存在配置的 `skin.figure` 和 `skin.scheme`。

## 构成

- `web/rig/rig.js`：一个小型的 Live2D 式渲染器。每个部件是一张贴图铺在一个网格上，网格点逐帧经过变形器链：
  `rot` 绕枢轴转动、缩放、平移，`warp` 在一个矩形上加位移场。WebGL2 绘制。
- `web/whale/figure.js`：模型本身。把 `createPet` 每帧给的数据（腿的角度、坐下程度、视线、眨眼、表情、说话幅度、横向惯性）
  换成变形器参数；后发、刘海、裙摆、尾巴、两只鲸鳍、呆毛、两只手臂各有一个弹簧；眼睛、嘴、腮红每帧画进一张脸部贴图，
  挂在头部的变形器上。画布放在宠物自己的 SVG 组里，舞台的位置、挤压、倾斜、转身照常作用。
- `web/whale/model.json`、`tex/`、`feat/`、`schemes/`：部件的位置（桌宠坐标，x=128 在身体下方，鞋底 y=256）、枢轴、贴图和五官贴图。

部件：尾巴、后发、远侧手臂、两条腿、上身、站姿裙子、坐姿下半身、近侧手臂、远侧鲸鳍、脸、近侧鲸鳍、头侧蝴蝶结、刘海（含两侧垂发）、头饰、呆毛。

坐下时下半身换成单独画的一张坐姿图（裙摆摊在地上、两腿向前伸、两只鞋都露出来）：身体下沉到一半时，
站姿的裙子和腿在两三帧内换成它，同时身体压扁一下；站起来是反过来。
头部转动靠视差：刘海和呆毛位移最大，脸、五官和近侧鳍其次，后发和远侧鳍反向移动。
常态眼睛直接从母版上按颜色拆成睫毛、眼白、虹膜三层（眼白在虹膜下面的部分用周围的白色延伸补齐）：眨眼时眼睑沿拟合的眼睑线下压并裁掉上方，视线移动只移虹膜。
开心、睡着、被拎、喜欢、晕、惊讶这几种眼睛和嘴是整张替换的贴图；生气和难过把眼睑向内侧压斜，嘴是画出来的下弯线。
其余表情复用这些贴图再加程序绘制：慌张用被拎时的 > < 眼，害怕用惊讶的眼睛，嘟嘴是缩小的 O 形嘴，
期待在虹膜上画白色星形高光，大哭在脸颊上画两道泪痕，疑惑把远侧眉毛单独抬高、头顶加问号，
嫌弃在刘海上画三道带浅色描边的黑线（深色头发上也看得清）。温柔是半垂的眼加浅浅的小弧嘴、内端稍抬的眉，头歪着，每 2.2 秒慢慢点一下头（`lean`，一次 3.2 秒的表情里点两下）；尴尬是笑眼配八字眉、一大滴汗、一道又宽又平的嘴（`MOUTH` 里 `[形状, 宽度]` 两个数字的写法），身子和头往后缩一点；偷笑是笑眼往旁边低一点看，每 1.6 秒憋不住抖一阵：`FACES` 给出 `titter`（0 到 1），她的上身绕腰压一压、脖子往下一点、鳍和呆毛跟着颤，Coo 是圆环一压一压。害羞、紧张、温柔、偷笑的视线和头会随时间变化（`FACES` 的 `f(t, pet)` 按 `pet.exprAt` 计时）。
难过时尾巴慢慢垂下（`MOOD` 的第三个值是垂尾幅度），回来时较快；每只鲸鳍有自己的抖动节奏：生气是一起嗡嗡震，慌张是不规则地抖，期待是一阵一阵扑。
`HEAD_PITCH` 的正值是低头（五官下移、头顶露出更多），往下看、睡觉、难过、大哭都是正值。
pet-core 为 Coo 设计的整组倾斜（倾听、点头、打瞌睡、晕乎乎时整个圆身体歪过去）在她身上换成低头、歪头，脚不离地；
只有腾空、被拎着、起跳下蹲和落地时整组倾斜，跑步保留一半前倾，跳舞的摇摆六成给整组。
点头、摇头、招手、鞠躬由她自己画：点头是低头两下，摇头是脸左右转，招手把近侧手臂举到肩高挥动（远侧手臂举起来会被身体和头发挡住），
鞠躬时上身（衣身、两只手臂和头）绕腰部枢轴 `waist` 前倾，裙子和腿不动；探头前倾一半，后缩时往后仰、手臂收紧。发抖、扑腾在 pet-core 的动作之外加上收紧手臂、垂下鲸鳍，或鲸鳍、尾巴、呆毛一起扑动。

## pet-core 的改动

`createPet` 的 `opts.figure` 接一个 `{ draw(petG, face, frame), anchors }`：给了它就不再往 `petG` 写内置的 Coo，
`frame` 在原有字段之外多带表情名、模式、模式时长、说话幅度、困意、坐下程度和朝向。
`anchors` 可覆盖视线原点、泪滴（`tears` 是大哭时两只眼睛下各自的起点，没给就只从 `tear` 一处冒）、睡眠 z、爱心、气泡和星光（`glints`，开心、得意时星光冒出的几处，没给就在气泡位置两侧）的位置。`figure.groupTilt(mode, tilt, lean)` 决定整组转多少度，
`frame` 带上 `tilt`、`lean`、`groupRot` 让模型自己处理剩下的部分；`figure.colors.z` 给睡眠 z 和跳舞的音符上色（否则用 Coo 的眼睛色）。
`frame.gesture` 是正在做的短手势 `{ kind, k }`（`k` 从 0 到 1，没有时为 `null`）；`figure.gestures` 列出模型自己画的手势，
列在里面的手势 pet-core 不再给整组加倾斜。
背过身（`away`）也作为 `frame.gesture` 送来（约 3.2 秒，`k` 前约 0.25 转过去、后约 0.2 转回来），朝向 `facing` 不变；Coo 没有背影，是把五官淡出再淡入（嘴那道缺口也收回平常大小，背着身不嘟嘴、不随说话开合）；
不在 `figure.gestures` 里列 `away` 的模型没有自己的样子，就整组转去朝另一边，过一会儿再转回来（`frame.facing` 跟着转）。
趴着（`poses.lie` 不为 `false`、画得出趴姿）时不送这个手势，只换成嘟嘴的脸，做到一半趴下也就此停下；画不出趴姿、照坐着画时照常送。
`figure.poses.back === true`（和 `poses.lie` 一样随帧报告）表示模型画得出自己的背影：转身时整组的水平缩放不再压到接近 0，
最窄到 85%，过中点直接翻面，`frame.facing`（-1 到 1，照旧是转到哪儿的原值）告诉模型转到了哪一步，由它自己画中间的样子。
趴下（`lie`）是坐下之后再趴：`frame.sit` 全程保持 1，`frame.lie` 从 0 到 1 是趴下的程度，`frame.prone` 表示这次休息是趴着的（趴着睡、从趴着起身时也是）。
趴着时偶尔的小动作（踢脚 `kick`、托下巴 `chin`、尾巴拍地 `thump`）作为 `frame.gesture` 送来，pet-core 自己不做任何处理。
`anchors.lie` 给出趴着时的同一组点，外加点击椭圆 `hit` 和半宽 `halfW`；没有它时 pet-core 按坐着处理点击、气泡和屏幕边缘，
`figure.poses.lie === false`（当前配色缺趴姿贴图）时也一样。所以不认识 `lie` 的模型照样能用：她只是一直坐着。
招手时，握拳的近侧手臂先往上抬，转过 70–95° 时（按手臂实际转到的角度，不按手势的时间）换成张开手的那张画（`poses.wave.rest` 是普通手臂转到多少度时与它指向一致），
它接着抬到位，手绕手腕挥动；趴着时不换。缺这两张图的配色照旧用握拳挥手。
比心（`heart`）时两条握拳的手臂先往胸前收，随即换成双手在胸前比心的那张画，从稍低处升到位，跟着节奏轻轻颠，眼睛换成爱心眼并冒爱心。
欢呼（`cheer`）时两条握拳的手臂先往上抬（近侧到 80°、远侧到 60°），在差约 15° 时（同样按手臂实际转到的角度，几乎是直接切换）各自换成举着张开手的那张画，
两者交接时指向一致，之后画的手臂接着抬到自己的角度（`poses.cheer.arms.*.rest`），跟着节奏上下晃；放下时倒过来，随握拳手臂的角度收回、在同一段角度交回。
缺这些图的配色照旧用握拳的手臂往上甩。
做「思考」表情、站着或坐着时，远侧手臂换成托腮的那张画：前臂绕肘部从下往上抬到下巴，抬到一半时和原来的远侧手臂交接；
它挂在脖子上，头动时手不离开下巴，思考时原本的歪头也收小。要用到远侧手臂的手势（欢呼、比心、喝茶、看书、翻滚、发抖、扑腾、后缩、探头）一开始她就把手放下，
托腮的前臂也只在欢呼、比心那几张画没盖住远侧手臂的地方出现。缺这张图的配色照旧不托腮。
托腮和比心的 `wrist` 是画里手所在的位置（测试按贴图的皮肤像素核对），它们不用 `rest`。
喝茶（`sip`，约 3.6 秒）和看书（`read`，约 4.4 秒）同比心一样：两条握拳的手臂往胸前收，随即换成双手捧着杯子（`poses.cup`）或翻开的书（`poses.book`）的那张画。
画的上半（手和杯子）挂在一个网格变形上：喝的那一下（`k` 约 0.38–0.66）抬到下巴，袖子跟着拉长，pet-core 同时让她闭眼、低一点头；杯口冒三缕热气（SVG，`wrist` 是杯口）。
看书时低头、眼皮半垂，视线沿一行字从左扫到右再回到行首。道具在各配色里颜色不变。Coo 没有手，用两只圆爪捧着自己画的杯子或书（书隔一会儿翻一页）。
翻滚（`roll`，约 1.5 秒）时 pet-core 让整组沿朝向走滚一圈的路（`ROLL_D`，半径 100 的球的周长；前面地方不够、后面更宽时先转身），
`k` 约 0.2–0.8 之间按 `rollTurn(k)` 缓入缓出地转一圈；滚的时候 `busy()` 为真，后面的动作等她站起来再做。Coo 是整个圆环绕环心转，
往下落到环底贴地、脚收起来；列了 `roll` 的模型自己画，没列的就沿路跳一下。大肥鱼蹲下，在 `k` 约 0.13–0.165 换成一张团成球的画（`poses.roll`），
它绕质心转，`support` 是每转 5° 时质心到最低点的距离，按它抬高放低，球总贴着地面；约 0.835–0.87 换回站姿弹起来。缺这张图的配色也沿路跳一下。
喷水（`spout`，约 1.6 秒）由 pet-core 画，任何模型都一样：先蹲一下，`k` 约 0.25 起从 `anchors.spout`（没给就在 `bubble` 下面一点；趴着用 `anchors.lie.spout`）
往上喷出一根水柱，到 0.45 前后散开，水珠（`spray` 粒子，圆珠带高光，和眼泪的形状分开）按重力落回地面；水用固定的蓝白色，不跟配色走。
大肥鱼自己画蹲和弹起、鲸鳍张开扑动、呆毛被顶起来、尾巴一甩；她的喷水点在呆毛后面的头顶，趴着时在趴姿头顶。
转身和转圈转到侧对你的那一下（`facing` 绝对值小于约 0.45），以及背过身（`away`）时，换成背面那张画；站着时才有（坐着、趴着照旧），
所以 `poses.back` 只在站着且当前配色有这张图时为真。背过身时她先往中间一挤，在最窄的那一刻正背面交换，转回来也一样；
没有背面图（坐着、缺图的配色）时只把脸转开、低一点头。
大肥鱼趴下时换成一张专门画的趴姿，不是骨架摆出来的：它在坐姿上淡入，等它完全不透明了坐姿才消失，起身时倒过来，所以两者不会互相透出来。
趴姿自己有几个变形：呼吸时背起伏，头绕托着它的下巴点头、摇头、探头，两只翘起的脚绕膝盖轮流踢（随心情快慢，睡着和倾听时不踢），
尾巴摆、垂、拍地；眨眼、打盹、睡着和闭眼的表情用闭眼贴片，其余表情靠头顶的符号和身体的动静。哪套配色缺趴姿的任一文件，
这套配色照常加载，只是 `figure.poses.lie` 为 false，她趴下时一直坐着。
不给 `opts.figure` 时行为与之前完全相同。

## 贴图来源

全部由 ChatGPT 生成（角色原设「溟月」，上善无形；DeepSeek 女仆二创，ZipZipPipe；围裙上的 Logo 是 DeepSeek、OpenAI、Anthropic、Google、阿里云、月之暗面、MiniMax 的商标图形）。
先定一张侧身二头身的母版立绘，之后所有分件都是对这张母版做「去掉某部分、补画下面」的编辑：去头、去手臂、去尾巴、去裙子露腿、
去前发、抹掉五官、只留头部、去头饰和鲸鳍、各表情。每张编辑图用 ECC 仿射配准回母版坐标（残差约 1 像素），
和上一步相减得到部件的遮罩；部件在母版里看得见的地方用母版原像素，被遮住的地方用编辑图补画的像素。
远侧手臂、脸后面的后脑勺头发、两只手臂切口的描线是把遮罩涂成品红色交给 ChatGPT 只在遮罩里重画的。
坐姿下半身是对母版做「坐下、腿前伸」的编辑，再去掉上半身得到的。每套配色是 ChatGPT 对母版做的只换颜色的重着色：
按部件在母版里露出的像素学出「原色 → 新色」的对应（颜色和位置上的近邻），再套到这个部件的全部像素上，
包括被遮住的部分。配色表是和 ChatGPT（Pro）按各家 Logo 的颜色一起定的。
围裙 Logo：先让 ChatGPT 在品红椭圆遮罩里把原来的鲸鱼抹成空白布面，再在同一个遮罩里逐个印上各家 Logo（给了 Logo 参考图）；
程序按「编辑图 = Logo × α + 空白布面 × (1 − α)」把 Logo 抠出来，贴到站姿裙子上，再按两张图里鲸鱼的位置换算贴到坐姿下半身上。
Harness 的黑鲸是原鲸鱼的形状改成黑灰色。

新增的姿势和手臂（趴姿 `tex/lie_*.png`、招手 `tex/arm_wave*.png`、托腮 `tex/arm_chin.png`、欢呼 `tex/arm_cheer_*.png`、比心 `tex/arm_heart.png`、杯子和书 `tex/arm_cup.png`、`tex/arm_book.png`、背面 `tex/back_body.png`、团成球 `tex/roll_ball.png`，
`model.json` 的 `poses`）也来自 ChatGPT 的图像模型（gpt-image-2.5，经本地代理用 ChatGPT 订阅调用），和原来的贴图同源：
把站姿渲染成一张参考图，对它做编辑。先试过本地的 FLUX.2-klein-4B，画风和比例都不如它（手画得太大，趴姿的头发变短）。
- 手臂：编辑只改手臂（举到头边张开手掌、托着下巴、双手举到头两侧、双手在胸前比心）。输出比参考图大约 1%，缩放回参考图尺寸再配准；
  在手臂的多边形里取皮肤、白袖口和深蓝袖子连同描边抠出来，袖子边缘混进后面头发颜色的像素去掉。举起的手臂画两份、挂在同一个变形上：
  整条手臂在原手臂的层（袖根藏在侧发或上身后面），只留手和小臂的一份在头部之上：招手和欢呼近侧的那份在头部所有部件之上（盖住鳍和发饰），
  欢呼远侧的那份在头发、鳍和头饰之上，但在蝴蝶结和呆毛之下。
  托腮的前臂和比心的两条前臂各只有一份，层在脸之上、刘海之下。换色只分底色（皮肤、白袖口）和衣服两个区域。
- 杯子和书：同手臂，编辑只改双手（捧着一只白马克杯、捧着一本深蓝封面翻开的书）。另画一个道具多边形，里面不是白底的像素都要，
  换色时原样保留；画里的热气不要，由程序画。
- 团成球：按「同一个角色在前滚翻中团成一个圆球、从侧面看、往右滚」生成，从四张里挑一张。它不和站姿配准，
  按凸包周长等于滚一圈的路（628 个单位）缩放，质心作转轴。换色同趴姿，按区域；头发和衣服都是深浅不一的蓝，用一个身体多边形分开。
- 背面：按「同一个角色、同一位置大小，从正后方看」生成，从四张里挑一张；脚底对齐站姿后整张一块（尾巴不拆开：拆开后它盖住的那块裙子是空的，
  一摆就露洞），尾巴的鳍在网格上摆。换色同趴姿，按区域。
- 趴姿：按「同一个角色趴在地上托着下巴、两脚翘起」生成，从多张里挑一张；闭眼是带遮罩的编辑，只允许改眼睛那块，
  眼睛周围几乎不变（整张图其余部分会被轻微重画，所以只取眼睛和脸颊做贴片）。白底抠成透明，镜像成和站姿一样面朝右，
  切成三块：除尾巴外的整个人、尾巴（向腿后多补一截，转动不露缝）、闭眼贴片。其他 7 套配色按区域换色：
  把像素标成头发、呆毛、发饰蝴蝶结、眼睛、鳍、尾巴、衣服、皮肤和白色，每个区域只用对应的站姿部件学「deepseek 色 → 该配色色」
  的对应表（鳍按明暗排名对应）。趴姿看不到围裙 Logo，所以不需要逐家贴 Logo。踢脚变形的膝盖、鞋子和小腿边界是搜出来的：
  网格不折叠、头不动、鞋子摆得开。
